# Pipeline Studio (โปรเจกต์ใหม่ — แยกจาก 7.web app)

เว็บแอปตามผังลายมือ 6 หน้า: จอมือถือซ้าย + แท็บ ①Input ②Process ③Release 💰Publish + ตั้งค่า ⚙
โทนสี earth tone · พอร์ต 8866

## รัน
```
python app.py        # http://127.0.0.1:8866
```

## กติกา bump เวอร์ชัน (ยกมาจากโปรเจกต์เดิม)
ต้องแก้ **3 ที่ให้ตรงกันเสมอ**: `app.py` (APP_VERSION) + `web/app.js` (EXPECTED_SERVER_VERSION) + `?v=` ใน `web/index.html` — ไม่ตรงจะขึ้นแบนเนอร์เตือนบนหน้า

## ข้อมูลที่คัดลอกมาจากโปรเจกต์เดิม (อ่านอย่างเดียว ไม่แตะต้นทาง)
- `data/gemini_api_key.bin` — key เดิม (DPAPI ถอดข้ามโปรเจกต์ได้ ยืนยันแล้ว)
- `data/flow_browser_profile/` — ล็อกอิน Google (Flow) + TikTok เดิม 136MB

## ผลตรวจ: อะไรจากโปรเจกต์เดิมที่ยัง "ไม่ได้" ยกมา (ตั้งใจไม่ยก)

โปรเจกต์เดิมมี 91 endpoint ของใหม่มี 45 — ส่วนที่ขาดคือฟีเจอร์คนละงาน ไม่ใช่ของที่ลืม:

| ของเดิม | ทำไมไม่ยกมา |
|---|---|
| `/api/jobs`, `/api/gemini/jobs`, `/api/sort/jobs` | ระบบถอดเสียง/จัดเรียงคลิปของแอปเก่า คนละงานกับผังนี้ |
| `/api/notes/*` (14 ตัว) | หน้าโน้ต + แชร์ผ่าน tunnel — ไม่มีในผัง |
| `/api/facebook-groups/*` (10 ตัว) | โพสต์ 6 กลุ่มผ่าน Chrome extension — ผังนี้โพสต์ Reels ผ่านมือถือแทน |
| `/api/access/*`, `/api/qr.png` | ระบบอนุญาตอุปกรณ์จากภายนอก — ของใหม่ล็อกเฉพาะ localhost |
| `/api/tiktok/login/*` (QR) | ของใหม่ล็อกอิน TikTok ผ่านโปรไฟล์เบราว์เซอร์แทน |
| `/api/shopee/*` (13 ตัว) | ผัง 24 ขั้นของ Shopee — ผังใหม่ใช้ Publish 1+6 ขั้นแทน |

(อัปเดต v6: ยกมาครบแล้วทั้ง `phone-post/push|launch|file` และ Wi-Fi `pair|connect|disconnect`
เป็นบล็อกย่อยในแผงซ้าย ไม่ได้แยกหน้าใหม่)
