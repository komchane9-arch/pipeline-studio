# ClipHarvest

แอป Android ที่ **ไล่ค้น Shopee/Lazada ตาม keyword แล้วเก็บลิงก์สินค้าให้เอง** (แนวเดียวกับ clippipe)
ทำงานในมือถือเองผ่าน **Shizuku** (สิทธิ์ระดับ adb) ไม่ต้องต่อคอม

## หน้าตา / การใช้งาน
1. ใส่ **keyword**
2. ติ๊ก **Shopee** และ/หรือ **Lazada**
3. ถ้าติ๊ก Shopee เลือกอย่างใดอย่างหนึ่ง: **เอาแค่ EXTRA COMM** หรือ **เอาทั้งหมด**
4. กด **เริ่มทำงาน** → แอปโผล่เป็น **ปุ่มลอย** (เริ่ม / หยุด / ลบ) → กด ▶ เริ่ม

## ทำงานยังไง (ลำดับ)
```
เปิดแอป (Shopee/Lazada) → พิมพ์ keyword ในช่องค้นหา → ค้นหา
  Shopee โหมด EXTRA COMM : แคปจอ → OCR หา "EXTRA COMM" → เข้าสินค้า → แชร์ → คัดลอกลิงก์ → เก็บ
  Shopee โหมดทั้งหมด / Lazada : เข้าสินค้าทุกตัว → แชร์ → คัดลอกลิงก์ → เก็บ
ติ๊กทั้ง Shopee+Lazada : ทำ Shopee จบ → เว้น ~90 วิ → ทำ Lazada
เว้นจังหวะแบบสุ่มทุกการกด (เลียนแบบคน ลดความเสี่ยงโดนกันบอท)
```

## ไฟล์แต่ละตัว
| ไฟล์ | หน้าที่ |
|---|---|
| `MainActivity.java` | หน้าตั้งค่า: keyword, ติ๊กแพลตฟอร์ม, โหมด Shopee, ปุ่มเริ่ม, ดูลิงก์/log |
| `RunService.java` | ปุ่มลอย (เริ่ม/หยุด/ลบ) + รันงานในเธรดพื้นหลัง (foreground service) |
| `Automation.java` | **กลไกขับ** — เปิดแอป/ค้นหา/หาสินค้า/แชร์/คัดลอกลิงก์/เก็บ (พิกัดปรับได้อยู่บนสุด) |
| `ShizukuShell.java` | สั่ง input/screencap ผ่าน Shizuku (เทียบเท่า adb บนเครื่อง) |
| `Ocr.java` | อ่านตัวอักษรจากภาพด้วย ML Kit — ใช้หา "EXTRA COMM" (อังกฤษ) |
| `ClipReader.java` | อ่าน/ตั้งคลิปบอร์ดผ่าน Shizuku (เก็บลิงก์ / paste keyword ไทย) |
| `Store.java` | เก็บค่าตั้งค่า + ลิงก์ (ไม่ซ้ำ) + log |
| `ShareInActivity.java` | ทางสำรอง รับลิงก์แบบแชร์ตรง |

## Build
เปิดใน Android Studio → sync → Run (ต้องมี Shizuku ทำงานในเครื่อง) ดูขั้นตอนเต็มใน
`สำหรับ-claude-ในเครื่อง.md`

## ข้อควรรู้
พิกัดการกดเป็นค่าเริ่มต้น ต้องจูนกับหน้าจอจริง (ดูหัวไฟล์ `Automation.java`)
การให้แอปกดแทนคนเพื่อเก็บลิงก์ affiliate จำนวนมากอาจขัดเงื่อนไข Shopee/Lazada — ใช้พอดี ไม่รัวเกินไป
