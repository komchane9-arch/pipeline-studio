# ClipHarvest

แอป Android ดักลิงก์ Shopee/Lazada จากคลิปบอร์ดเบื้องหลัง แล้วเก็บ + ส่งต่อ — แนวเดียวกับ clippipe
ใช้ **Shizuku** เพื่ออ่านคลิปบอร์ดตอนแอปไม่ได้อยู่หน้าจอ (Android 10+ ห้ามแอปทั่วไปทำ)

## แนวคิด (ทำงานยังไง)

```
กด "คัดลอกลิงก์" ของสินค้า EXTRA COMM ในแอป Shopee/Lazada
        ↓ (ลิงก์ไปอยู่ในคลิปบอร์ด)
CaptureService อ่านคลิปบอร์ดทุก ~0.9 วิ ผ่าน Shizuku
        ↓ กรองเฉพาะข้อความที่มีคำที่ตั้งไว้ (shopee.co.th, s.shopee, lazada.co.th, s.lazada)
เก็บลิงก์ (ไม่ซ้ำ) ในเครื่อง + ถ้าตั้ง URL ไว้ก็ POST ส่งต่อ
```

## ไฟล์แต่ละตัวทำอะไร

| ไฟล์ | หน้าที่ |
|---|---|
| `ClipReader.java` | **หัวใจ** — อ่านคลิปบอร์ดผ่าน Shizuku (เรียก system service `clipboard` ในนาม shell). ใช้ reflection ไล่หาเมธอด `getPrimaryClip` แล้วเติมพารามิเตอร์ตามชนิด จึงทนต่อความต่างของแต่ละเวอร์ชัน Android (attributionTag ใน 13, deviceId ใน 14) |
| `CaptureService.java` | foreground service คอย poll คลิปบอร์ดทุก pollMs — เจอลิงก์ใหม่ที่เข้าเงื่อนไขก็เก็บ + ส่งต่อ มีแจ้งเตือนค้าง + ปุ่มหยุด |
| `Store.java` | เก็บค่าตั้งค่า (คำกรอง, URL ส่งต่อ, ช่วง poll) และรายการลิงก์ที่ดักได้ (ไม่ซ้ำ) ใน SharedPreferences |
| `Forwarder.java` | POST ลิงก์ไปยัง URL ที่ตั้งไว้ (ถ้าตั้ง) |
| `MainActivity.java` | หน้าจอ: สถานะ Shizuku + ขอสิทธิ์, ปุ่มเริ่ม/หยุด, ตั้งค่า, ดู/คัดลอก/ล้างรายการลิงก์ |
| `ShareInActivity.java` | ทางสำรอง — รับลิงก์แบบแชร์ตรง (กด "แชร์ → ClipHarvest" ในแอป Shopee) โดยไม่พึ่ง Shizuku |

## ต่างจาก clippipe ตรงไหน

เหมือนกันเกือบหมด (ดักคลิปบอร์ด, กรองคำ, ส่งต่อ URL, เก็บไม่ซ้ำ) — ตัวนี้เขียนใหม่จากศูนย์
เพราะไม่มี source เดิมของ clippipe ยังไม่มี: ปุ่มลอย, โหมดธนาคาร, สำรอง Google Drive,
"เก็บ N ร้าน" — เพิ่มทีหลังได้ถ้าต้องการ

## ข้อควรรู้
