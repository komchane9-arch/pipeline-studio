# งานต่อสำหรับ Claude ในเครื่อง (build + ทดสอบ ClipHarvest)

โปรเจกต์นี้เขียนบน Claude cloud ซึ่ง build/ทดสอบ Android ไม่ได้ (ไม่มี Android SDK และเครือข่ายบล็อก
Google Maven) ฝากเครื่องที่มี Android Studio ทำต่อตามนี้ ถ้าติดตรงไหนให้หยุดแล้วบอกเจ้าของ

โฟลเดอร์: `clip-harvest/` · แพ็กเกจ: `th.pipeline.harvest` · มือถือทดสอบ serial `93a21824`

## 1. เปิดโปรเจกต์และ build
- เปิด Android Studio → Open → เลือกโฟลเดอร์ `clip-harvest`
- ปล่อยให้ Gradle sync (โหลด Shizuku api/provider 13.1.5 จาก Maven) ถ้า sync แดง ให้แก้ตามที่ Studio แนะนำ
  (เวอร์ชัน Android Gradle Plugin ใน `build.gradle` = 8.5.2, Gradle 8.7 — ปรับให้ตรงกับ Studio ที่ติดตั้งได้)
- Build > Make Project ให้ผ่านก่อน ถ้ามี error ให้แก้แล้วรายงานเจ้าของว่าแก้อะไร

## 2. ติดตั้งลงมือถือ
- `./gradlew installDebug` หรือกด Run ใน Android Studio (เลือกเครื่อง 93a21824)
- ยืนยันว่ามีแอป **ClipHarvest** ในเครื่อง

## 3. ตั้ง Shizuku (จำเป็น — หัวใจของแอป)
- ในมือถือมีแอป Shizuku อยู่แล้ว (`moe.shizuku.privileged.api`)
- เปิด Shizuku แล้ว Start ผ่านทางใดทางหนึ่ง: ผ่าน Wi-Fi debugging หรือผ่าน adb
  (`adb shell sh /storage/.../start.sh` ตามที่ Shizuku บอก) — Shizuku ต้องขึ้นว่า "กำลังทำงาน"
- เปิดแอป ClipHarvest → กด **ขอสิทธิ์ Shizuku** → อนุญาต → บรรทัดสถานะต้องขึ้น "Shizuku: พร้อม ✓"

## 4. ทดสอบว่าดักลิงก์ได้จริง
- ในแอป ClipHarvest กด **▶ เริ่มดักจับ** (แจ้งเตือนค้างจะขึ้น "กำลังดักลิงก์…")
- เปิด Shopee → เข้าสินค้า EXTRA COMM → แชร์ → **คัดลอกลิงก์**
- กลับมา ClipHarvest (หรือดึงแจ้งเตือน) — ต้องเห็นจำนวน "เก็บแล้ว" เพิ่มขึ้น และลิงก์โผล่ในรายการ
- ถ้าเก็บได้ = ผ่าน ✓ รายงานเจ้าของ พร้อมบอกว่าลิงก์ที่เก็บหน้าตาเป็นยังไง

### ถ้าไม่เก็บ ให้ไล่ตรงนี้
- สถานะขึ้น "Shizuku: ยังไม่พร้อม" → ย้อนไปข้อ 3
- แจ้งเตือนขึ้น "เริ่มไม่ได้: Shizuku ยังไม่พร้อม" → Shizuku ยังไม่ได้ start หรือยังไม่ได้ให้สิทธิ์
- Shizuku พร้อมแต่ไม่เก็บ → น่าจะเป็นที่ `ClipReader.read()` อ่านคลิปบอร์ดไม่ได้บนเวอร์ชัน Android นี้
  ให้ดู logcat กรอง `th.pipeline.harvest` และลองแก้การเรียก `getPrimaryClip`
  (พารามิเตอร์ packageName อาจต้องเป็น `"com.android.shell"` อยู่แล้ว, userId 0 — ตรวจว่า throw อะไร)
- ตั้งค่า "ตรวจคลิปบอร์ดทุกกี่มิลลิวินาที" ลองลดเหลือ 700

## 5. (หลังผ่าน) ต่อเข้ากับ pipeline links / ค้นหาอัตโนมัติ
- ถ้าอยากให้ลิงก์ไหลเข้าระบบต่อ: ใส่ URL ในช่อง "ส่งลิงก์ไปที่ URL" (เช่น endpoint ของ 8877
  ที่รับลิงก์เข้าคิวสายคลิป) แอปจะ POST ลิงก์ดิบไปให้ทุกครั้งที่ดักได้
- ส่วน "ค้นหาตาม keyword แล้วไล่กดคัดลอกลิงก์อัตโนมัติ" ยังไม่ได้ทำในตัวนี้ — เป็นงานถัดไป

## หมายเหตุการเซ็นแอป
ตอนนี้ตั้งให้ release ใช้กุญแจ debug (`signingConfig signingConfigs.debug`) เพื่อให้ build/ลงง่าย
ถ้าจะแจกจริงค่อยเปลี่ยนเป็นกุญแจของตัวเอง
