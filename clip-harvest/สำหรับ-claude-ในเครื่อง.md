# งานต่อสำหรับ Claude ในเครื่อง — ClipHarvest v0.2 (ไล่ค้น Shopee/Lazada เก็บลิงก์เอง)

เขียนบน Claude cloud ซึ่ง build/ทดสอบ Android ไม่ได้ ฝากเครื่องที่มี Android Studio ทำต่อ
โฟลเดอร์ `clip-harvest/` · แพ็กเกจ `th.pipeline.harvest` · มือถือทดสอบ `93a21824`

## แอปนี้ทำงานยังไง
1. หน้าหลัก: ใส่ **keyword**, ติ๊ก **Shopee/Lazada**, ถ้าติ๊ก Shopee เลือก **EXTRA COMM / เอาทั้งหมด**
2. กด **เริ่มทำงาน** → ขอสิทธิ์ Shizuku + สิทธิ์แสดงทับแอป → โผล่เป็น **ปุ่มลอย** (เริ่ม/หยุด/ลบ)
3. กด ▶ บนปุ่มลอย → `RunService` รัน `Automation.run()` ในเธรดพื้นหลัง:
   - เปิดแอป Shopee → พิมพ์ keyword (paste รองรับไทย) → ค้นหา
   - โหมด EXTRA COMM: แคปจอ → **OCR หา "EXTRA COMM"** → กดเข้าสินค้า → แชร์ → คัดลอกลิงก์ → อ่านคลิปบอร์ดเก็บ
   - โหมดทั้งหมด: กดสินค้าทีละช่องในกริด → แชร์ → คัดลอกลิงก์ → เก็บ
   - ถ้าติ๊กทั้งคู่: ทำ Shopee จบ → เว้น ~90 วิ → ทำ Lazada
4. ทุกขั้นเขียน log (ดูในหน้าหลัก หรือ `adb logcat`)

## ขั้นตอนทำ (1-2-3-4)

**1. build** — เปิดโฟลเดอร์ `clip-harvest` ใน Android Studio → Gradle sync (โหลด Shizuku + ML Kit)
→ Build > Make Project ให้ผ่าน ถ้า error แก้แล้วรายงานว่าแก้อะไร

**2. ติดตั้ง** — `gradlew installDebug` หรือกด Run เลือกเครื่อง `93a21824`

**3. ตั้ง Shizuku** — เปิดแอป Shizuku (มีในเครื่อง) แล้ว Start → เปิด ClipHarvest กด **ขอสิทธิ์ Shizuku**
→ อนุญาต → สถานะขึ้น "Shizuku: พร้อม ✓" · กด **เริ่มทำงาน** ครั้งแรกจะให้อนุญาต "แสดงทับแอปอื่น" ด้วย

**4. ทดสอบทีละส่วน** (สำคัญ — อย่ารันยาวรวดเดียว) ใส่ keyword สักคำ ติ๊ก Shopee + EXTRA COMM แล้ว:
   - กดเริ่มบนปุ่มลอย ดู log ว่าไปถึงขั้นไหน แล้ว **จูนพิกัดที่ยังไม่ตรง**

## จุดที่ต้องจูน (พิกัดเป็นค่าประมาณ ต้องดูจอจริง)
อยู่ใน `Automation.java` ด้านบน (เป็นสัดส่วน 0..1 ของจอ):
- `SEARCH_BAR_X/Y` — ช่องค้นหาบนสุด
- `SHARE_ICON_X/Y` — ปุ่มแชร์มุมขวาบนหน้าสินค้า (เป็นไอคอน OCR จับไม่ได้ ต้องใช้พิกัด)
- `COPY_LINK_X/Y` — ปุ่ม "คัดลอกลิงก์" ในแผงแชร์คอมมิชชั่น
- การเล็งสินค้าเหนือป้าย EXTRA COMM (`cardUp`) และกริดใน `allProducts()`

## ความเสี่ยงที่อาจต้องแก้
- **`ShizukuShell` ใช้ `Shizuku.newProcess` ผ่าน reflection** — ถ้าเวอร์ชัน Shizuku นี้ไม่มีเมธอดนี้
  (exec/screencap คืนค่าว่างทุกครั้ง) ต้องเปลี่ยนไปใช้ **Shizuku UserService** แทน (ผมเขียนให้ได้ บอกมา)
- **พิมพ์ไทยด้วย paste** — ถ้า paste ไม่เข้า ให้เช็ก keyevent PASTE(279) หรือสลับไปใช้ ADBKeyboard
- **OCR "EXTRA COMM"** เป็นอังกฤษ ML Kit ละตินอ่านได้ ถ้าอ่านไม่เจอให้ลดการย่อภาพ/เพิ่มความคมชัด

## ให้ Claude cloud ช่วยจูนสด
มี connector ต่อมือถือ `93a21824` อยู่แล้ว — หลัง build+ลงเสร็จ บอก Claude cloud ได้เลย
มันเปิดแอป กดปุ่มลอย ดู log และแคปจอจริงเพื่อไล่แก้พิกัดให้ตรงได้
