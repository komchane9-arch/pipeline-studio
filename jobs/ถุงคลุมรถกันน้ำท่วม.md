# งานคลิป: ถุงคลุมรถกันน้ำท่วม — แนวเพื่อนบอกเพื่อน + สาธิตใช้งานจริง

> ไฟล์นี้เขียนจาก Claude บน cloud ซึ่งเข้า Shopee และ Google Flow ไม่ได้
> **ให้ Claude บนเครื่องหลัก (ที่รัน Pipeline Studio) ทำตามขั้นตอนข้างล่าง**
> ข้อมูลสินค้าจริง (ขนาด วัสดุ ราคา รูป) ให้สายคลิปดึงจากลิงก์ Shopee เอง
> ห้ามเอาตัวเลขสเปกจากไฟล์นี้ไปใส่คลิป เพราะไฟล์นี้ไม่ได้เห็นหน้าสินค้า

## ขั้นตอนสำหรับ Claude บนเครื่องหลัก

อ่าน `SHOPEE-SCRAPE-RULES.md` และ `SHOPEE-VIDEO-RULES.md` ก่อนเริ่ม ตามกติกาของโปรเจกต์
ทุกคำสั่งยิงที่ clip server `http://127.0.0.1:8877` (ต้องเปิด Studio ไว้ก่อน ด้วย `start_studio.bat`)

1. **ส่งลิงก์เข้าคิว**
   ```bash
   curl -s -X POST http://127.0.0.1:8877/api/jobs -H "Content-Type: application/json" \
     -d "{\"links\": \"https://s.shopee.co.th/6fhYuk01LM\"}"
   ```
   จด job id ที่ได้กลับมา แล้วดูสถานะที่ `GET /api/jobs` หรือบนหน้าเว็บ 8877

2. **ขั้นเลือกรูป (`image_review`)**: ตรวจว่ามีรูปที่เห็นสินค้า **ตอนคลุมรถแล้ว** อย่างน้อย 1 ใบ
   และรูปตอนพับเก็บ ถ้าไม่มี ให้สลับเอาจากคลังรูปก่อนกด `img_ok`

3. **ขั้นสตอรีบอร์ด (`storyboard_review`)**: สั่งแก้ให้เป็นสไตล์นี้ด้วยข้อความในหัวข้อ "คำสั่งแก้สตอรีบอร์ด"
   ```bash
   curl -s -X POST http://127.0.0.1:8877/api/jobs/<job_id>/revise -H "Content-Type: application/json" \
     -d @- <<'EOF'
   {"target": "storyboard", "instruction": "<วางข้อความจากหัวข้อ คำสั่งแก้สตอรีบอร์ด>"}
   EOF
   ```
   อ่านสตอรีบอร์ดที่ได้ ถ้าตรงตามโครงข้างล่างแล้วค่อยกด `sb_ok` (`POST /api/jobs/<job_id>/action` body `{"action":"sb_ok"}`)

4. **ขั้นบทพูด (`script_review`)**: สั่งแก้ด้วย `target: "script"` และข้อความจากหัวข้อ "คำสั่งแก้บทพูด"
   ตรวจว่าจุดเด่นที่พูดถึงมาจากคำบรรยายสินค้าจริงใน Shopee ไม่ได้แต่งขึ้นเอง แล้วกด `sc_ok`

5. **ขั้นเจนคลิป (`ready_flow` → `generating`)**: ปล่อยให้ Flow ทำตามปกติ
   **ห้ามเปลี่ยนรุ่นวิดีโอที่กินเครดิตเพิ่ม** (ดู `FLOW-PLAYBOOK.md`)

6. **ขั้นตรวจคลิป (`video_review`)**: ดูว่าฉากสาธิตเรียงถูก (คลี่ → คลุม → รูดซิป/รัด → ผลลัพธ์)
   ถ้าผิด ใช้ `POST /api/jobs/<job_id>/regen` พร้อม `note` บอกว่าฉากไหนผิดยังไง ไม่ใช่เจนซ้ำด้วยคำสั่งเดิม

7. **รายงานกลับ**: ส่งพาธไฟล์คลิปสุดท้าย + แคปชั่นจากหัวข้อ "แคปชั่นโพสต์" ให้เจ้าของ
   **ยังไม่ต้องโพสต์ TikTok หรือ Facebook** จนกว่าเจ้าของดูคลิปแล้วสั่งเอง

## คำสั่งแก้สตอรีบอร์ด

```
ปรับเป็นสไตล์ "เพื่อนบอกเพื่อน" + สาธิตการใช้งานจริง ยาวรวมไม่เกิน 30 วินาที
คนพูดเป็นคนธรรมดาที่ใช้ของจริง ไม่ใช่พิธีกรขายของ ถือกล้องเองหรือมีเพื่อนถ่ายให้
ฉากต้องดูเหมือนถ่ายเองที่บ้าน ลานจอดรถ หรือหน้าบ้าน ไม่ใช่สตูดิโอ

โครงฉาก:
1) ฮุก 0-3 วิ: หันกล้องหาเพื่อน/คนดู หน้าตาจริงจัง ข้างหลังเห็นฝนตกหนักหรือน้ำเริ่มขังถนน
   ข้อความบนจอ: "ใครบ้านน้ำท่วมง่าย ดูก่อนเลย"
2) ปัญหา 3-6 วิ: ภาพน้ำขังถึงล้อรถ หรือรถจอดริมถนนตอนฝนตก บอกว่ากลัวน้ำเข้ารถ
3) เปิดของ 6-9 วิ: หยิบถุงคลุมรถที่พับเก็บอยู่ออกมาจากกล่อง/ถุง ให้เห็นว่าพับเก็บได้เล็ก
4) สาธิต 9-20 วิ (ฉากสำคัญที่สุด ต้องเห็นมือทำจริงทีละขั้น):
   - คลี่ถุงออกวางบนพื้น
   - ขับรถหรือเข็นรถเข้าไปจอดบนถุง
   - ดึงขอบถุงขึ้นคลุมรอบตัวรถ
   - รูดซิปหรือรัดปิดจนมิด (ใช้วิธีปิดตามที่เห็นในรูปสินค้าจริง)
5) ผลลัพธ์ 20-25 วิ: รถอยู่ในถุงที่ปิดสนิท น้ำรอบๆ แต่ตัวรถแห้ง คนพูดยิ้มโล่งใจ
6) ปิด 25-30 วิ: ชี้ลงล่าง ข้อความบนจอ "โค้ด ruen01 ลดเพิ่ม 800.-" และ "พิกัดในคอมเมนต์"

ห้าม: ภาพรถลอยน้ำหรือโดนน้ำพัด (ดูเหมือนสินค้าทำไม่ได้), ตัวเลขสเปกที่ไม่มีในหน้าสินค้า,
คำว่า "กันน้ำ 100%" หรือ "รับประกันไม่เสียหาย" ถ้าหน้าสินค้าไม่ได้เขียนไว้แบบนั้น
```

## คำสั่งแก้บทพูด

```
เขียนบทพูดภาษาไทยแบบเพื่อนคุยกับเพื่อน ใช้คำว่า "แก" "เรา" "อะ" "นะ" ได้ตามธรรมชาติ
ประโยคสั้น พูดเร็ว มีจังหวะตื่นเต้นตอนสาธิต ไม่อ่านสเปกยาวๆ
จุดเด่นที่พูดถึงต้องมาจากคำบรรยายสินค้าใน Shopee เท่านั้น เลือกมา 2-3 ข้อ

แนวบท (ปรับตามจุดเด่นจริงของสินค้า):
"แก ๆ บ้านใครน้ำท่วมง่ายฟังก่อน ปีที่แล้วรถเราเกือบจมแล้วอะ
 ปีนี้เลยได้ตัวนี้มา ถุงคลุมรถกันน้ำท่วม พับเก็บได้แค่นี้เอง
 ดูนะ คลี่ออก ขับรถขึ้นไปจอด ดึงขึ้นมารอบคัน รูดปิด จบ!
 [จุดเด่นจริง 1] [จุดเด่นจริง 2]
 น้ำมาเท่าไรก็ไม่ต้องลุ้นแล้ว
 ใครสนใจ ใส่โค้ด ruen01 ลดเพิ่มอีก 800 นะ พิกัดอยู่ในคอมเมนต์ รีบเลยก่อนของหมด"
```
