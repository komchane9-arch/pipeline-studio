# ระบบหาลิงก์อัตโนมัติ Shopee/Lazada ตาม keyword → ส่งเข้า pipeline links

สถานะ: สำรวจ flow จริงแล้วบางส่วน ยังไม่เริ่มสร้าง

## สิ่งที่เจ้าของต้องการ

- พิมพ์ keyword ไว้ล่วงหน้าได้หลายคำ แล้วระบบรันเอง
- เลือกได้ว่าจะรัน Shopee / Lazada / ทั้งคู่
- **Shopee**: หาสินค้าที่เป็น extra comm ทั้งหมด แล้ว copy ลิงก์
- **Lazada**: copy ลิงก์ของสินค้าที่ค้นเจอทุกตัว
- ส่งลิงก์ที่ได้ไปยังแอป `th.pipeline.links` ในมือถือ

## สิ่งที่เจอจากการเปิดแอปจริง (มือถือ 93a21824)

1. **สินค้า EXTRA COMM มีป้ายสีส้มติดในผลค้นหาปกติเลย** (ใต้ราคา เขียน "EXTRA COMM")
   บัญชีนี้ล็อกอิน affiliate อยู่ Shopee จึงโชว์ป้ายให้เห็นในหน้าค้นหา ไม่ต้องเข้าหน้าพิเศษ
   → เป้าหมายชัด: ในผลค้นหา หาการ์ดที่มีป้าย EXTRA COMM
2. **แคปหน้าจอได้ปกติ** (screenshot ผ่าน adb ใช้ได้)
3. **อ่านผังหน้าจอ (uiautomator dump) บน Shopee ไม่ได้** — คืน None ทั้งสองครั้ง
   Shopee กันการอ่านโครงหน้าจอไว้ (พฤติกรรมกันบอทของแอปช้อปปิ้ง)

## ผลต่อวิธีสร้าง (สำคัญ)

เพราะอ่านผังหน้าจอ Shopee ไม่ได้ แต่แคปจอได้ การหา/กดต้องทำแบบ **มองจากภาพ**:
- แคปหน้าจอ → หาตำแหน่งป้าย "EXTRA COMM" และการ์ดสินค้าด้วยการวิเคราะห์ภาพ/OCR → กดตามพิกัด
- ไม่ใช่การอ่าน element เหมือนที่ Studio ทำกับ Facebook (Facebook อ่าน uiautomator ได้)

เรื่องนี้กระทบทางเลือก "แอปติดตั้งบนมือถือ (AccessibilityService)" ที่เจ้าของเลือกไว้:
- AccessibilityService ก็อ่านหน้าจอ Shopee ที่กันไว้อาจไม่ได้เหมือนกัน (ต้องทดสอบ)
- ถ้าอ่านไม่ได้ แอปบนมือถือต้องพึ่งการมองภาพ + OCR บนเครื่องเอง ซึ่งหนักและกินแบต

## ทางเลือกที่เป็นไปได้ (รอเจ้าของตัดสิน)

| ทาง | ทำงานยังไง | ข้อดี | ข้อเสีย |
|---|---|---|---|
| A. ขับจากคอมผ่าน adb + มองภาพ/OCR | คอมแคปจอมือถือ หา EXTRA COMM จากภาพ กดผ่าน adb แล้วแชร์ลิงก์เข้า th.pipeline.links | สร้าง/แก้/ทดสอบได้จาก cloud ทันที (มี connector แล้ว), ใช้เครื่องมือ OCR บนคอมได้เต็มที่ | คอมต้องเปิดและต่อมือถือไว้ |
| B. แอปบนมือถือ (AccessibilityService) | แอปรันเองในมือถือ อ่าน/กดแอปอื่น | รันเองไม่ต้องพึ่งคอม | Shopee อาจบล็อก accessibility ด้วย, build/debug ยาก, เสี่ยงพังเวลา Shopee อัปเดต |

**หมายเหตุ:** ต้องยืนยันด้วยว่า `th.pipeline.links` รับลิงก์เข้าทางไหน (Android Share / ACTION_SEND, clipboard, หรือ intent เฉพาะ) — ดูได้จาก manifest ของแอปนั้น

## ขั้นตอน flow (ทั้งสองทางใช้ลำดับเดียวกัน)

1. เปิด Shopee → แตะช่องค้นหา → พิมพ์ keyword → ค้นหา
2. เลื่อนผลลัพธ์ทีละหน้า แคปจอ หา EXTRA COMM
3. เปิดสินค้าที่เจอ → แชร์ → คัดลอกลิงก์ affiliate
4. ส่งลิงก์เข้า th.pipeline.links
5. วนจนครบ keyword และครบแพลตฟอร์มที่เลือก
6. Lazada: เหมือนกันแต่ไม่กรอง extra comm — เก็บลิงก์ทุกตัวที่ค้นเจอ

## ทดสอบขับจริงจาก cloud แล้ว (29 ก.ย. 2569) — ได้ผลดี

ขับ Shopee จากคอมผ่าน connector + มองภาพจากแคปหน้าจอ (ไม่ใช้ uiautomator ซึ่งพังบนเครื่องนี้):
1. เปิด Shopee → แตะช่องค้นหา → ENTER → เข้าหน้าผลค้นหาได้
2. **อ่านป้าย EXTRA COMM จากภาพได้ชัดเจน** ระบุตำแหน่งการ์ดสินค้าได้
3. แตะเปิดสินค้า EXTRA COMM → แตะปุ่มแชร์ (มุมขวาบน) → ได้หน้า **"แชร์เพื่อรับค่าคอมมิชชั่น"**
   - โชว์อัตราค่าคอม (เช่น 7%, ฿8.05) ยืนยันว่าเป็นสินค้า extra comm จริง
   - มีปุ่ม **"คัดลอกลิงก์"** = ก๊อปลิงก์ affiliate, ปุ่ม **"อื่นๆ"** = ตัวเลือกแชร์ระบบ
4. ยังไม่ได้ยืนยันว่า th.pipeline.links โผล่ในหน้าแชร์ "อื่นๆ" ไหม (โดนตัวกรองบล็อกตอนแตะชิดขอบ)

**สรุป: flow ทั้งหมดทำได้จริงจาก cloud ด้วยการมองภาพ** ไม่ต้องพึ่ง uiautomator/accessibility เลย

## ทางเลือกสถาปัตยกรรม (ต้องเลือกก่อนสร้างต่อ)

| | ขับจาก cloud (มองภาพ) | แอปบนมือถือ (ตามที่เลือกไว้) |
|---|---|---|
| อ่าน EXTRA COMM | **ทำได้แล้ววันนี้** (cloud Claude มองภาพ) | ยังไม่แก้ได้: uiautomator พัง, accessibility ยังไม่พิสูจน์, OCR ต้องใช้ Gradle |
| "รันเอง ไม่ต้องเปิดคอม" | ไม่ใช่ ต้องมีคอม+connector+เครดิต | ใช่ |
| เริ่มใช้ได้ | ทันที | ต้อง build + แก้ปัญหาการอ่านจอก่อน |

## เรื่องที่ต้องระวัง

- Shopee/Lazada กันบอท: ต้องเว้นจังหวะแบบสุ่ม กดไม่ถี่ ไม่งั้นบัญชี affiliate เสี่ยงโดนจำกัด
- บัญชีที่ใช้เป็นบัญชี affiliate จริงของเจ้าของ — เริ่มจากทดสอบทีละ keyword ก่อน
