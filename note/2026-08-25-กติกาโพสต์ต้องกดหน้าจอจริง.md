## ส่วนที่ 1 — บทสนทนาทั้งหมด

**ผู้ใช้สั่ง**

> บันทึกไว้หน่อยการโพสต์ facebook reels, titok video , shopee video , instagram reels
> ต้องเป็นการกดหน้าจอจริงแบบที่เขียนไว้ทั้งหมดทุกจุด ยกเว้นได้อย่างเดียวคือตอนเปิดแอพขึ้นมา

**ที่ทำ** — เขียนกติกานี้ลง 3 ที่ที่คนละกลุ่มจะไปเจอ แล้วรันด่านตรวจกับของที่มีอยู่จริง

2. หัวไฟล์ `publish_flow.py` — ที่ที่คนมาเพิ่ม TikTok/Instagram จะเปิดก่อน
3. memory ส่วนตัว — ที่ที่แชทใหม่ทุกแชทเห็นตั้งแต่เริ่ม

**ที่มาของคำสั่งนี้** — ก่อนหน้านั้นผู้ใช้ถามว่า *"ขั้นตอน FB reels, shopee video
ในการกดทั้งหมด เป็นการกดที่หน้าจอแบบคนกดใช้ไหม ไม่ใช่ยิง injection"*
ผมไล่โค้ดแล้วยืนยันว่าใช่ทุกจุด เขาจึงสั่งให้ล็อกไว้เป็นกติกา รวมถึงปลายทางที่ยังไม่ได้ทำ

### 2. สรุปผลงานทั้งหมดในแชทนี้

**เขียนกติกาลง 3 ที่**

| ที่ | ใครจะเจอ |
|---|---|
| `CLAUDE.md` ข้อ 2.7 | ทุกแชทที่จะแตะโค้ดโปรเจกต์นี้ |
| หัวไฟล์ `publish_flow.py` (กล่องกรอบ) | คนที่มาเพิ่มปลายทางใหม่ |
| memory `posting-must-be-real-screen-taps.md` | แชทใหม่ทุกแชทตั้งแต่ข้อความแรก |

**เนื้อกติกา**

- ทุกจุดต้องกดผ่านระบบรับสัมผัสของ Android เหมือนนิ้วคนจริง
- **ห้าม** เรียก API ของแพลตฟอร์ม · ฉีดโค้ดเข้าแอป · accessibility service กดแทน ·
  ยิง intent ข้ามขั้นตอนที่ควรกด · ใช้ `am start` เปิดหน้าจอกลางๆ เพื่อลัดขั้นตอน
- **ยกเว้นได้อย่างเดียว** เปิดแอปด้วย `monkey`/`am start` เพราะเป็นการเปิดโปรแกรม
  ไม่ใช่การข้ามขั้นตอนในโปรแกรม หลังแอปเปิดแล้วต้องกดเองทั้งหมด
- กติกาประกอบ 4 ข้อ: ทุกขั้นต้องพิสูจน์ก่อนไปต่อ · ต้องสุ่มเยื้องจุดกดเสมอ ·
  พิกัดห้ามฝังตายในโค้ด · ปิดการสุ่มตอนเทรน

**เพิ่มด่านตรวจถาวร** ตามกติกาข้อ 2.6 (บั๊กเก่าต้องกลายเป็น pre-flight check)

```bash
grep -rn "graph.facebook.com\|/me/videos\|open_api\|upload_video\|AccessibilityService" *.py
```

**ผลรันจริง — ไม่เจออะไรเลย ✅**

**แก้ตัวตรวจของตัวเองระหว่างทาง** — ครั้งแรกผมใส่คำว่า `accessibility` ลอยๆ ในด่าน
ผลคือมันไปจับ `accessibility_caption` ใน `fb_posts_parse.py` ซึ่งเป็นชื่อฟิลด์ JSON
ของ Facebook สำหรับคำบรรยายรูป **ไม่เกี่ยวกับการกดแทนเลย** — ด่านที่ร้องผิดบ่อยๆ
สุดท้ายจะไม่มีใครฟัง จึงเปลี่ยนเป็น `AccessibilityService` ให้จับเฉพาะของจริง

**ยืนยันสภาพโค้ดปัจจุบัน**

```
จุดกดที่ผ่านตัวสุ่ม (context.tap_at)   6 จุด
จุดกดที่เรียก context.tap ตรงๆ         0 จุด
ด่านตรวจ API/injection                 ไม่เจออะไรเลย
```

## หมายเหตุสำคัญสำหรับคนที่มาทำต่อ

1. **เพิ่มปลายทางใหม่ (TikTok / Instagram) ต้องทำตามกติกาข้อ 2.7 ทุกข้อ**
   ห้ามคิดว่า "แพลตฟอร์มนี้มี API ให้ใช้อยู่แล้ว จะง่ายกว่า" — ผู้ใช้สั่งไว้ชัดว่าไม่เอา
2. **ข้อยกเว้นมีข้อเดียวจริงๆ คือเปิดแอป** อย่าตีความขยายเป็น "ก็เปิดหน้าอัปโหลด
   ด้วย intent เลยสิ ก็เหมือนเปิดแอป" — นั่นคือการข้ามขั้นตอนในโปรแกรม ไม่ใช่การเปิดโปรแกรม
3. **ด่านตรวจต้องจับเฉพาะของจริง** คำว่า `accessibility` ลอยๆ จับผิดได้ (ชื่อฟิลด์
   JSON ของ Facebook) ใช้ `AccessibilityService` แทน — ด่านที่ร้องผิดบ่อยจะไม่มีใครฟัง
