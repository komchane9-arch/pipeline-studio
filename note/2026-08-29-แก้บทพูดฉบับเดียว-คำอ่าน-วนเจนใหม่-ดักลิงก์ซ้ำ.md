### 2.1 บทพูดเหลือฉบับเดียว — `chatgpt_driver.py` · `clip_store.py`

**ปัญหาเดิม** ถาม ChatGPT สองรอบ รอบแรกได้คำสั่ง Flow (มีบทฝังในบรรทัด `Audio:`)
รอบสองขอ "บทพูด" แยกอีกที → **ได้บทคนละฉบับ ตรงกัน 0 จาก 65 ใบ**
ตัวที่เจ้าของเห็นและกดอนุมัติคือฉบับรอบสอง แต่ตัวที่ Veo อ่านคือฉบับรอบแรก

**แก้แล้ว**

| ไฟล์ | ทำอะไร |
|---|---|
| `chatgpt_driver.py` | ตัดรอบขอบทพูดทิ้ง · เพิ่ม `audio_lines()` แกะบทจากบรรทัด `Audio:` แทน |
| `clip_store.py` | `set_script()` **เขียนบทกลับลงบรรทัด `Audio:` ในคำสั่ง Flow ด้วย** |
| `clip_store.py` | ทำไม่ได้ไม่เงียบ — เก็บเหตุผลไว้ที่ `script_sync` ให้เอาไปบอกผู้ใช้ |

**ผลพลอยได้** ตัดการถาม ChatGPT ไปหนึ่งรอบ เร็วขึ้นและกินโควตาน้อยลง

**พิสูจน์แล้ว** — เขียนบทใหม่กลับลงคำสั่งจริงของใบ `16820466802` แล้วอ่านกลับมา

### 2.2 พูด 3 ฉากจาก 5 · ไม่เกิน 100 ตัวอักษร — `chatgpt_driver.py`

ค่าคงที่ใหม่ `SPEAK_SCENES = 3` · `SPEECH_MAX_CHARS = 100`
`FLOW_AUDIO_RULE` เขียนใหม่ทั้งข้อ สั่ง ChatGPT 5 ข้อ

```
1) ภาพ 5 ฉากเหมือนเดิม แต่ให้มีเสียงแค่ 3 ฉาก เลือกฉากที่ขายของได้ดีที่สุด
2) บทพูดรวมทุกฉากห้ามเกิน 100 ตัวอักษรไทย
3) เขียนเป็นคำอ่านคั่นพยางค์ด้วยขีด
4) รูปแบบบรรทัด Audio: ต้องตรงเป๊ะ
5) ห้ามคำภาษาอังกฤษปนในบทพูด
```

ตัวตรวจใหม่ `flow_audio_problem()` ตรวจครบ 4 เรื่องแล้วขอใหม่ 1 รอบถ้าไม่ผ่าน
— **ทดสอบครบทุกเคสแล้ว**

| ป้อนอะไรเข้าไป | ตัวตรวจตอบ |
|---|---|
| ครบกติกา | ✅ ผ่าน |
| ไม่มีบรรทัดเสียง | ไม่มีบรรทัดสั่งเสียงพูดสักฉาก — คลิปที่ได้จะเงียบ |
| 121 ตัวอักษร | บทพูดรวม 121 ตัวอักษร เกินเพดาน 100 |
| ไม่มีขีดคำอ่าน | บทพูดยังไม่ได้เขียนเป็นคำอ่านคั่นพยางค์ด้วยขีด |
| พูด 4 ฉาก | มีฉากพูด 4 ฉาก เกินที่กำหนดไว้ 3 ฉาก |

### 2.3 คำอ่านคั่นพยางค์ — `thai_speech.py` · `clip_app.py`

**เครื่องนี้ไม่มีไลบรารีตัดคำไทย** (ไม่มีทั้ง `pythainlp` และ `ssg`) จึงเขียนกฎเอง

ของใหม่ใน `thai_speech.py`

```python
split_syllables("ทำงาน")   → ['ทำ', 'งาน']
spell_out(ข้อความ)         → ใส่ขีดให้คำไทย ไม่แตะอังกฤษ/ตัวเลข
speech_ready(text, level, spell=True)
```

**หลักการ** ไล่หาพยางค์จากซ้ายไปขวาแบบ**ถอยหลังได้** แล้วเลือกทางที่คะแนนดีที่สุด
(พยัญชนะลอยเดี่ยวโดนหักคะแนน) — ต้องมีการถอยหลังถึงจะได้ `ผ้า-ขน-แกะ`
แทนที่จะได้ `ผ้าข-น-แกะ`

กฎที่ต้องใส่เพิ่มระหว่างทาง แต่ละข้อมาจากคำที่แยกผิดจริง

| กฎ | คำที่ทำให้ต้องเพิ่ม |
|---|---|
| ควบกล้ำมีชุดจำกัด ไม่ใช่ควบได้ทุกตัว | `ไวรัส` เคยกลายเป็นควบ `วร` แล้วไม่ยอมแยก |
| `ห` `อ` `ฮ` เป็นตัวสะกดไม่ได้ | `ประหยัด` เคยได้ `ประห-ยัด` |
| พยางค์ไม่มีสระเขียนแต่มีตัวสะกดเป็นเรื่องปกติ | `มั่นคง` เคยแยกไม่ลงเลย |
| `ย` เป็นส่วนหนึ่งของสระ เ-ีย | `เตียงนอน` เคยได้ `เตีย-ง-นอน` |
| ห้ามหยิบตัวสะกดถ้าฉีกควบกล้ำถัดไป | `สะดวก` เคยได้ `สะด-วก` |
| `อย` เป็นตัวนำของพยางค์ถัดไป | `ครบทุกอย่าง` เคยได้ `ครบ-ทุ-กอ-ย่าง` |

`clip_app._speech_prompt()` ใส่คำอ่าน **เฉพาะบรรทัด `Audio:`** ไม่แตะคำบรรยายภาพ
ต่อเข้าจุดเจนแล้วทั้งสองจุด — **ใส่ซ้ำสองรอบได้ผลเท่าเดิม** (ChatGPT เขียนขีดมาให้แล้วก็ไม่พัง)

### 2.4 เจอคลิปเสีย วนเจนใหม่อัตโนมัติ 1 รอบ — `clip_app.py` · `clip_store.py`

```python
AUTO_REGEN_CHECKS   matches_script · split_screen · speech_clear · text_readable
AUTO_REGEN_LIMIT    1
```

เจอ → ลบไฟล์คลิปเดิม → ตั้งใบงานกลับไปขั้นเจน → ปลุกตัวรัน → บอกในแชท
เจนใหม่แล้วยังเจอ → **หยุด** บอกในแชทว่าหยุดแล้วเพราะอะไร

ตัวนับรอบเก็บถาวรที่ `clip_store.set_auto_regen()` — **ห้ามเก็บในหน่วยความจำ**
เพราะรีสตาร์ตแล้วตัวนับหายจะวนเจนไม่จบ ซึ่งเป็นเครดิต Flow จริงทุกรอบ

⚠️ **ไม่รวม `speech_ok`** (อ่านคำเพี้ยนเล็กน้อย) ทั้งที่น่ารำคาญเหมือนกัน
เพราะวัดแล้วเจอ 42% — ใส่เข้าไปจะเจนใหม่เกือบครึ่งของทุกคลิป
ทางแก้ของอาการนั้นคือคำอ่าน ไม่ใช่การเจนใหม่

**ถ้ากติกานี้มีผลกับคลิป 51 ใบเก่า** จะสั่งเจนใหม่ 25 ใบ (49%)
แต่ตัวเลข "เสียงไม่ตรงบท" 18 ใบในนั้นเป็นของที่**เทียบผิดฉบับ** ใบใหม่จะต่ำกว่านี้มาก

### 2.5 ดักลิงก์ซ้ำข้ามข้อความ — `clip_app.py`
