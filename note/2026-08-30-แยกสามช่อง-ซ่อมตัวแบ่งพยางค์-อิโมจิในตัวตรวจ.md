### ข. ตัวแบ่งพยางค์ไทย — กระทบบทพูดที่ส่งให้ Veo

**นี่คือของที่แรงที่สุดของวัน** `spell_out()` ใช้ตัวแบ่งนี้เขียนคำอ่านให้ Veo
ประโยคที่แบ่งไม่ออกถูกส่งไป **ไม่มีขีดสักตัว** แล้ว Veo อ่านผิดทั้งฉาก

```
ก่อน:  spell_out('พับขาตั้งออกมากางได้เลย')  →  พับขาตั้งออกมากางได้เลย
หลัง:                                        →  พับ-ขา-ตั้ง-ออก-มา-กาง-ได้-เลย
```

แก้ 3 จุดใน `thai_speech.py`

1. **`อ` สองตัวติดกัน = พยัญชนะต้น ไม่ใช่สระ** — ไม่มีคำไทยไหนใช้ `ออ` เป็นสระพยางค์เดียว
   ไม่มีข้อนี้ `ตั้งออก` แบ่งไม่ออกทั้งก้อน
2. **แบ่งสองรอบ เข้มก่อน ผ่อนทีหลัง** — กฎ "ไม้หันอากาศต้องมีตัวสะกด" จริงกับคำไทยแท้
   แต่ไม่จริงกับคำยืม (`อัตโนมัติ` = อัต-โน-**มั**-ติ) รอบแรกใช้กฎเข้ม แบ่งไม่ออกค่อยผ่อน
   **สองรอบจึงได้ทั้งของเดิมไม่เปลี่ยน และของที่เคยเงียบได้ขีด**
3. **ข้อยกเว้น `อย` ต้องมีสระตามหลัง** — `อย่าง` `อยู่` ใช่ แต่ `อย` เปล่าๆ ไม่ใช่คำ
   ไม่จำกัด `ไร้รอย` ถูกแยกเป็น `ไร้ร-อย`

### ค. แฮชแท็กตัดกลางคำ

ต้นเหตุ 2 ชั้น ทั้งคู่คือการตัดด้วยจำนวนตัวอักษรดิบ
1. `hashtag.py:220` ตัดที่ **20 ตัวอักษรเป๊ะ** — ทุกอันที่หลุดออกไปยาว 20 ตัวพอดี
2. `count_syllables()` เป็นตัวประมาณ นับ `รับประกันสามปี` ได้ 6 (ของจริง 5)

แก้: ใช้ `thai_speech.split_syllables()` ทั้งนับและตัด + ตัดเศษหัวคำท้ายทิ้ง
**เฉพาะตอนที่ตัดจริง** (ไม่งั้น `รองรับสรีระ` กลายเป็น `รองรับสรี`)

### ฉ. เครื่องมือใหม่ 2 ตัว — เกิดจากความผิดพลาดของผมเอง

**`load_check.py`** — ตรวจว่าไฟล์ Python **โหลดขึ้นจริง** ไม่ใช่แค่ไวยากรณ์ถูก

ผมวางตัวแปรไว้หลังบรรทัดที่เรียกใช้ `ast.parse` บอกผ่าน แต่เซิร์ฟเวอร์ตายทันทีที่เปิด
ด้วย `NameError` **ดับไป 8 นาที** ตัวเฝ้าไล่ปลุก 5 รอบและตายทุกรอบ

```bash
python load_check.py                        # ตรวจโครงสร้างทั้งโปรเจกต์ (102 ไฟล์)
python load_check.py --import clip_app.py   # ลองโหลดจริงในสนามทดสอบ
```

**`restart_clip.py`** — รีสตาร์ตแบบไม่ฆ่างานที่กำลังเดิน

สคริปต์ชั่วคราวของผมเขียน `for _ in range(120): ... break` แล้ว `taskkill` ต่อ
พอครบ 600 วินาทีมันก็**เดินหน้าฆ่าเหมือนคิวว่างจริง** ฆ่างานเจนคลิปกลางคันตอน 15:50:56

```bash
python restart_clip.py --check     # ดูอย่างเดียว
python restart_clip.py --wait 20   # รอนานขึ้น · หมดเวลาแล้ว **ไม่ฆ่า**
```

ตัวนี้ลองโหลดโมดูลก่อนปิดของเก่าด้วย — **ปิดก่อนแล้วค่อยรู้ว่าเปิดไม่ขึ้น คือความผิดพลาดเดิมทั้งดุ้น**
