### 1.3 ตัวเลขที่เปลี่ยนวิธีคิด

**สมาชิกเยอะ ≠ คนเล่น**

```

รีวิวครอบจักรวาล      420,000 คน  →  ไลก์เฉลี่ย 2.25

```


## 3. งานค้างที่ต้องทำต่อ

### รอเจ้าของ

- **รีสตาร์ต 8866 เช้าวันที่ 1 ก.ย.** — เจ้าของสั่งให้พัก จะทักมาเอง
  ตอนนี้ `/api/fb/group-board` ยังตอบ 404 กระดานจึงยังไม่ขึ้น
- **140 กลุ่มก้ำกึ่งรอกดรับ/ตัด** — พอรีเสร็จจะกดได้จากหน้าเว็บ

  **ยังไม่ได้ถามว่า Bot10 ล็อกอิน Facebook ไว้พร้อมหรือยัง**

### รอเราทำต่อ

- ยังไม่ได้เห็นกระดานบนจอจริง — ตรวจได้แค่ว่า API คืนข้อมูลถูก

- ตัวกางคำตอบที่ถูกพับ **ยังไม่เคยเจอหน้าจริง** ผ่านแค่หน้าจอจำลอง 27 เคส
