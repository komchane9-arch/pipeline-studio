# แผนเจนสตอรีบอร์ดใหม่ทั้งกอง โดยมีพรีเซนเตอร์เป็นผู้หญิงคนเดิมทุกใบ

**เจ้าของสั่ง 9 ก.ย. 2569** — *"ให้เขียน flow (ไม่ต้องรันเอง) รันสร้างสตอรี่บอร์ดใหม่
ทั้งหมดโดยมี presenter เป็นผู้หญิงที่ผมแนบ แต่เก็บ storyboard เก่าไว้ด้วยนะ"*

> **สถานะ: เขียนแผนไว้เฉยๆ ยังไม่ได้รัน** ตามที่สั่ง
> ต้องตัดสินใจ 4 เรื่องในหัวข้อ "ต้องตอบก่อนเริ่ม" ก่อนถึงจะกดรันได้

---

## 1. ขนาดงานจริง (วัดเมื่อ 9 ก.ย. 2569)

```
ใบงานทั้งหมด                468 ใบ
  มีสตอรีบอร์ดแล้ว           301 ใบ   ← ของเก่าที่ต้องเก็บไว้
  มีสตอรีบอร์ด แต่ยังไม่เจน    98 ใบ
  เจนคลิปแล้ว                348 ใบ
  โพสต์ไปแล้ว                341 ใบ   ← ทำใหม่แล้วต้องโพสต์ทับไหม ยังไม่ตอบ

ไฟล์ภาพสตอรีบอร์ดในเครื่อง   324 ไฟล์
```

**ถ้าทำครบ 468 ใบ = ภาพที่ต้องให้ ChatGPT วาดใหม่ราว 468 ใบ**
(ใบละ 1 ภาพ เป็นแผ่นรวม 5 ฉากในภาพเดียว)

## 2. ต้องตอบก่อนเริ่ม — 4 เรื่อง

### 2.1 "ทั้งหมด" คือกี่ใบ

| ทางเลือก | จำนวน | ผลที่ตามมา |
|---|---|---|
| ก. เฉพาะที่ยังไม่โพสต์ | **127 ใบ** | ปลอดภัยสุด ของที่ลงไปแล้วไม่ต้องยุ่ง |
| ข. เฉพาะที่ยังไม่เจนคลิป | **120 ใบ** | ทำแล้วได้ใช้จริงทุกใบ |
| ค. ทุกใบ | **468 ใบ** | ใบที่โพสต์ไปแล้ว 341 ใบต้องเจนคลิปใหม่ + โพสต์ใหม่ด้วย ไม่งั้นสตอรีบอร์ดใหม่ไม่ได้ใช้ |

**ผมแนะนำ ข.** — ทำแล้วได้ใช้ทันทีทุกใบ ไม่มีของค้าง
ถ้าเลือก ค. ต้องคิดเรื่องเครดิต Veo อีก 468 × 15 = **7,020 หน่วย** (ตอนนี้เหลือ 50)

### 2.2 รูปพรีเซนเตอร์ต้องเซฟลงเครื่องก่อน

**ผมดึงรูปที่แนบในแชทลงเครื่องเองไม่ได้** — เจ้าของต้องเซฟให้

```
เซฟไว้ที่  data/presenter/presenter-01.jpg
```

ควรมีหลายมุมถ้ามี (ยืนเต็มตัว · ครึ่งตัว · หันข้าง) ยิ่งมีมุมมาก ChatGPT ยิ่งวาดให้เหมือนขึ้น

### 2.3 พรีเซนเตอร์อยู่ในทุกฉาก หรือบางฉาก

กติกาที่ใช้อยู่ตอนนี้คือ **"ทุกฉากต้องเห็นสินค้าครบทั้งชิ้น"** ถ้าเพิ่มคนเข้าไปในเฟรมด้วย
พื้นที่ของสินค้าจะเล็กลง

| ทางเลือก | ข้อดี | ข้อเสีย |
|---|---|---|
| ทุกฉาก | จำหน้าได้ ดูเป็นแบรนด์เดียวกัน | สินค้าเล็กลงทุกฉาก · หน้าคนเพี้ยนได้ 5 จุดต่อใบ |
| ฉากแรกกับฉากปิด | สินค้ายังเด่น · หน้าเพี้ยนน้อยลง 60% | ฉากกลางไม่มีคน |

**ผมแนะนำแบบสอง** ด้วยเหตุผลในข้อ 4.1

### 2.4 ของเก่าเก็บแบบไหน

**เก็บทั้งไฟล์ภาพและข้อมูลในใบงาน** — รายละเอียดในหัวข้อ 3

## 3. วิธีเก็บของเก่า (ต้องทำก่อนแตะอะไรทั้งสิ้น)

⚠️ **ของเดิมทับทิ้งหมด** ตรวจโค้ดแล้ว — `save_storyboard()` เขียนทับ `run["storyboard"]`
และภาพใหม่ดาวน์โหลดลงโฟลเดอร์ `storyboard/` ชื่อขึ้นต้น `storyboard-` เหมือนเดิม
**ถ้าไม่ย้ายของเก่าออกก่อน ของเก่าหายถาวร**

```
ก่อนทำ                        หลังทำ
<ใบงาน>/storyboard/           <ใบงาน>/storyboard/            ← ของใหม่
  storyboard-01.png           <ใบงาน>/storyboard-เก่า-<วันที่>/
                                storyboard-01.png            ← ของเก่า ย้ายมาทั้งดุ้น
                                run-เก่า.json                 ← สำเนาใบงานก่อนแก้
```

ในใบงานเก็บเพิ่ม

```json
"storyboard_history": [
  { "at": "2026-09-09T21:00:00",
    "folder": "storyboard-เก่า-20260909-210000",
    "frames": ["storyboard-01.png"],
    "flow_prompts": [...],
    "script": [...],
    "why": "ทำใหม่เพื่อใส่พรีเซนเตอร์" }
]
```

**เก็บคำสั่ง Flow กับบทพูดเก่าด้วย ไม่ใช่แค่ภาพ** — ถ้าเก็บแค่ภาพแล้ววันหนึ่งอยากย้อนกลับ
จะย้อนไม่ได้ เพราะสามอย่างนี้ผูกกันเป็นชุด

**สำรองทั้งกองเป็น zip ก่อนอีกชั้น** เหมือนที่สายโพสต์ทำตอนคืนใบ Reels

```
data/backup/storyboard-ก่อนใส่พรีเซนเตอร์-<วันที่เวลา>.zip
```

## 4. ความเสี่ยงที่ต้องรู้ก่อนตัดสินใจ

### 4.1 🔴 หน้าพรีเซนเตอร์จะไม่เหมือนกันทุกใบ — นี่คือความเสี่ยงอันดับหนึ่ง

ChatGPT วาดภาพใหม่ทุกครั้งจากศูนย์ **ไม่ได้ก๊อปหน้าจากรูปต้นแบบ** ต่อให้แนบรูปไปด้วย
หน้าที่ออกมาจะ "คล้าย" ไม่ใช่ "เหมือน" และจะเพี้ยนคนละทางในแต่ละใบ

```
ทำ 468 ใบ × ฉากละ 1 หน้า × 5 ฉาก = 2,340 ครั้งที่ต้องวาดหน้าคนเดิม
```

**ยังไม่มีตัวตรวจว่าหน้าที่ได้เหมือนต้นแบบไหม** ระบบจะเดินหน้าเก็บภาพที่หน้าเพี้ยน
ไปเรื่อยๆ โดยไม่มีอะไรฟ้อง — เป็นรูปแบบเดียวกับที่เคยทำให้ 141 ใบเจนโดยไม่มีสตอรีบอร์ด

**เสนอ**: ทำ 5 ใบก่อน แล้วเจ้าของดูด้วยตาว่ารับได้ไหม **ก่อนปล่อยทั้งกอง**

### 4.2 🔴 พร้อมประจำตัวของ custom GPT อาจสั่งห้ามมีคน — และเราแก้ไม่ได้

พร้อมที่ฝังอยู่ในตัว GPT บน chatgpt.com **เราอ่านไม่ได้และแก้ไม่ได้** เคยขัดกับกติกา
ที่เราส่งไปทับมาแล้ว **3 จุด** และจุดหนึ่งทำให้ทำสำเร็จแค่ **3%** ของคลิป
(สั่งให้มีตัวหนังสือไทย แต่พร้อมหลักสั่ง "no text")

ในโค้ดฝั่งเราเองก็มีบรรทัดที่สั่ง **"ไม่ต้องมีคนหรือโลโก้แบรนด์"** อยู่
([chatgpt_driver.py:1551](chatgpt_driver.py:1551)) ต้องแก้ก่อน

**ต้องเช็คก่อนปล่อยทั้งกอง** — เจ้าของเปิดพร้อมของ custom GPT ดูว่ามีคำว่า
no people / no humans / no person ไหม ถ้ามีต้องแก้ที่ chatgpt.com ก่อน

### 4.3 🟠 โควตารูปของ ChatGPT จะหมดกลางทาง

วัดเมื่อ 31 ส.ค. — โควตาหมดแล้วขึ้นว่าคืนใน **12 ชั่วโมง 21 นาที**
ยังไม่รู้ว่าวาดได้กี่ใบต่อรอบ

ระบบกันไว้แล้ว (9 ก.ย.) — เจอโควตาหมดจะ **หยุดส่งเอง แล้วกลับมาทำต่อเองเมื่อถึงเวลา**
ไม่ต้องมีคนเฝ้า แต่แปลว่างานจะกินเวลาหลายวัน ไม่ใช่คืนเดียวจบ

### 4.4 🟠 เวลาที่ใช้

วัดจากของจริง ใบละราว **4–5 นาที**

```
120 ใบ (ทางเลือก ข.)   ≈  9–10 ชั่วโมงเดินเครื่อง  + เวลารอโควตาคืน
468 ใบ (ทางเลือก ค.)   ≈  35–39 ชั่วโมงเดินเครื่อง + เวลารอโควตาคืน
```

## 5. ขั้นตอน (flow)

### ขั้น 0 — เตรียม (คนทำ)

```
[ ] เซฟรูปพรีเซนเตอร์ลง  data/presenter/presenter-01.jpg
[ ] เปิดพร้อมของ custom GPT บน chatgpt.com เช็คว่ามีข้อห้ามเรื่องคนไหม
[ ] ตอบ 4 ข้อในหัวข้อ 2
```

### ขั้น 1 — สำรองของเก่า (ไม่แตะอะไรอย่างอื่น)

```
เครื่องมือใหม่:  tools/archive_storyboards.py
ค่าเริ่มต้นเป็น dry-run ต้องใส่ --apply ถึงจะแก้จริง

  1. อ่านใบงานทุกใบในขอบเขตที่เลือก
  2. zip โฟลเดอร์ storyboard/ + run.json ทั้งกองไว้ที่ data/backup/
  3. ย้าย storyboard/ → storyboard-เก่า-<วันที่เวลา>/
  4. จด storyboard_history ลง run.json (ภาพ + คำสั่ง Flow + บทพูด)
  5. ตรวจซ้ำ: ทุกใบต้องมีของเก่าอยู่ครบก่อนไปขั้นถัดไป
     ขาดแม้ใบเดียว = หยุดทั้งงาน
```

**หยุดถ้า**: zip เขียนไม่สำเร็จ · ย้ายโฟลเดอร์ไม่สำเร็จ · จำนวนไฟล์ก่อน/หลังไม่ตรง

### ขั้น 2 — แก้กติกาที่ส่งเข้า ChatGPT

```
ไฟล์:  clip_rules.py  (เพิ่มกติกาใหม่ 1 ข้อ ติ๊กเปิด/ปิดได้)
       chatgpt_driver.py:1551  (ลบ "ไม่ต้องมีคนหรือโลโก้แบรนด์" ออกจากทางถอย)
```

กติกาใหม่ต้องบอก ChatGPT ว่า

- แนบรูปพรีเซนเตอร์ไปด้วยทุกครั้ง พร้อมบอกว่า **"ผู้หญิงคนนี้ต้องเป็นคนเดิมทุกฉาก"**
- อยู่ฉากไหนบ้าง (ตามที่ตอบข้อ 2.3)
- **ห้ามบังสินค้า** — สินค้ายังต้องเห็นครบทั้งชิ้นตามกติกาเดิม
- ท่าทาง: ยืนข้างสินค้า มือเชิญ ไม่ใช่ถือสินค้า (ถือแล้วสินค้าโดนมือบัง)

### ขั้น 3 — ลองกับ 5 ใบก่อน ⛔ ห้ามข้าม

```
เลือก 5 ใบที่สินค้าต่างกันมาก (ทีวีใหญ่ · ของชิ้นเล็ก · เก้าอี้ · สายชาร์จ · โคมไฟ)
รันแล้วส่งภาพให้เจ้าของดูทั้ง 5 ใบ
```

**เจ้าของต้องตอบ 3 คำถาม** ก่อนไปต่อ

```
1. หน้าเหมือนรูปต้นแบบพอไหม
2. สินค้ายังเห็นครบไหม
3. หน้าใน 5 ใบเป็นคนเดียวกันไหม
```

ไม่ผ่านข้อไหน → กลับไปขั้น 2 แก้กติกา **ห้ามปล่อยทั้งกอง**

### ขั้น 4 — ปล่อยทั้งกอง

```
ทีละ 8 ใบตามกติกาข้อ 2.7.1 (เพดานที่มีอยู่แล้ว)
เจอโควตารูปหมด → หยุดเอง กลับมาทำต่อเองเมื่อโควตาคืน
ทุกใบต้องได้ภาพจริงถึงจะนับว่าผ่าน (ด่านขั้นที่ 3 ที่ทำไว้แล้ว)
```

**รายงานความคืบหน้าเข้าแชททุก 20 ใบ** — ทำแล้วกี่ใบ เหลือกี่ใบ มีใบไหนติดปัญหา

### ขั้น 5 — ตรวจก่อนปิดงาน

```
[ ] ทุกใบมีภาพสตอรีบอร์ดใหม่จริง (ไม่ใช่แค่สถานะบอกว่าเสร็จ)
[ ] ทุกใบยังมีของเก่าอยู่ใน storyboard-เก่า-*
[ ] สุ่ม 20 ใบเปิดดูด้วยตา — หน้าเหมือนกันไหม สินค้าครบไหม
[ ] จำนวนใบก่อน/หลังเท่ากัน ไม่มีใบหาย
```

## 6. จุดหยุดอัตโนมัติ

ระบบต้องหยุดเองและแจ้ง ถ้าเจอข้อใดข้อหนึ่ง

```
· ของเก่าย้ายไม่สำเร็จแม้ใบเดียว
· ได้ภาพ 0 ใบติดกัน 3 ใบ
· โควตารูป ChatGPT หมด          (หยุดเอง กลับมาเองแล้ว)
· เจ้าของยังไม่อนุมัติผล 5 ใบแรก
```

## 7. สิ่งที่ยังไม่ได้ทำในแผนนี้

- **ตัวตรวจว่าหน้าเหมือนต้นแบบไหม** — ยังไม่มี ต้องใช้ตาคนดูเท่านั้น
  ถ้าอยากได้ตัวตรวจอัตโนมัติ เป็นงานแยกอีกก้อน
- **เจนคลิปใหม่** — แผนนี้ทำแค่สตอรีบอร์ด ไม่ได้รวมการเจนคลิปใหม่
- **โพสต์ทับของเก่า** — ไม่ได้อยู่ในแผนนี้เลย

## 8. สรุปสิ่งที่รอเจ้าของ

```

2. เลือกขอบเขต: ก. 127 ใบ · ข. 120 ใบ · ค. 468 ใบ   (แนะนำ ข.)
```
