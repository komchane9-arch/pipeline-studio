## 2. สรุปผลงานทั้งหมดในแชทนี้

### `clip_results.py` — สมุดผลลัพธ์ (commit `60de6a7` · `589854b`)

อ่านตัวเลขรวมของบัญชีจากหน้า "การวิเคราะห์" ใน TikTok Studio จดเป็นประวัติ
คิดอัตราถูกใจให้ และ **เตือนเมื่อต่ำกว่าค่าปกติ**

```bash
python clip_results.py ช่อง      # อ่านจากมือถือแล้วจด
python clip_results.py           # ดูรายงาน
```

**เคยลองจับคู่ยอดวิวรายคลิป 2 วิธี ไม่ผ่านทั้งคู่ จึงปิดไว้ไม่ให้เขียนข้อมูล**

| วิธี | ผล | เหตุผล |
|---|---|---|
| จับคู่ตามลำดับช่องในตาราง | ถูก 1 จาก 4 | กล่อง "แบบร่าง" แทรกหัวแถว · อ่านเลขตกบางช่องแล้วลำดับเลื่อนทั้งแถว · อ่านป้ายแจ้งเตือน "12" มาเป็นยอดวิว |
| จับคู่ด้วยลายนิ้วมือภาพ | ถูก 2 จาก 4 | ฮับ UGREEN สองใบหน้าตาเกือบเหมือนกัน ระยะห่าง 8–24 บิต ตัดเส้นไม่ได้ |

ลองทั้งเฟรมแรกและทุกวินาทีของคลิปแล้ว **ตัวเลขที่ผูกผิดคลิปแย่กว่าไม่มีตัวเลข**
เพราะพาไปสรุปผิดว่าสินค้าแบบไหนมีคนดู

### `screen_read.py` — ตัวอ่านหน้าจอกลาง (commit `561dd2b`)

```python
view = screen_read.read(serial)
if not view.readable:
    raise RuntimeError(view.why)     # บอกสาเหตุจริง ไม่ใช่ "ไม่พบ X"
if view.has("ร้านค้า"): ...
```

`View` ตอบครบว่า **อ่านได้ไหม · อ่านมาทางไหน · แอปไหนอยู่หน้าสุด · มีกล่องระบบบังไหม
· ถ้าอ่านไม่ได้เพราะอะไร** และ `why_not_found()` แต่งข้อความล้มที่บอกสาเหตุจริงให้

รวมของที่เคยกระจายใน `tiktok_publish_bot.py` มาไว้ที่เดียว — **ชื่อเดิมใช้ได้ครบ**
ทดสอบแล้วผัง TikTok ยังเดินได้เหมือนเดิม

**เพิ่มด่านที่เคยไม่มี** — `uiautomator` ล้มแล้วไฟล์ผังเก่ายังอยู่ ทำให้เคยอ่าน
ผังของเมื่อสิบนาทีก่อนมาโดยไม่มีอะไรบอก (เป็นเหตุให้ค่าที่วัดขัดกันเองจนไล่ผิดทาง
อยู่พักใหญ่) ตอนนี้ล้มแล้วไม่อ่านของเก่าเด็ดขาด

## 3. สรุปงานค้างที่ต้องทำต่อทั้งหมด

### รอเจ้าของตัดสิน

- **อัตราถูกใจ 0.25% กับผู้ติดตามเพิ่ม 0** — ตัวเลขบอกว่าปัญหาอยู่ที่เนื้อหาคลิป
  ต่อให้เร่งระบบแค่ไหนก็ไม่เปลี่ยน **ต้องตัดสินใจว่าจะแก้ที่คลิปยังไง**
- **เครดิต Flow เหลือ 20 หน่วย** — 113 ใบที่ยังไม่มีคลิปเดินต่อไม่ได้
- **ที่ว่างเหลือ 16 GB** — `data/evidence` กิน 367 MB และโตทุกวัน
- **สวิตช์อัตโนมัติปิดหมด 8 ตัว** — ไม่มีอะไรเดินเอง ต้องสั่งด้วยมือทุกครั้ง

### รอเราทำต่อ

- **ขั้น "เปิดหน้าสินค้า" ของผัง TikTok ยังล้มเป็นบางครั้ง** — "แท็บร้านค้าเปิดแล้ว
  แต่ผลสินค้ายังไม่โหลด" ยังไม่ได้ไล่ว่าต่างจากรอบที่ผ่านยังไง
- **งานลง 6 ใบค้างอยู่** ลงได้ 0 จาก 6 เพราะหยุดตั้งแต่ใบแรก
- **ยังไม่ได้เอา `screen_read` ไปใช้ใน `tiktok_product_link.py`** — ยังมีตัวอ่าน
  ของตัวเองอยู่
- **จับคู่ยอดวิวรายคลิป** — ทางที่เหลือคือหน้า "เนื้อหา" ใน TikTok Studio ซึ่ง
  น่าจะแสดงแคปชันคู่กับยอดวิว (แคปชันเป็นตัวระบุที่ไม่ซ้ำ)
- **ข้อ 4-7 จากรายการข้อเสนอ** — เทสแบบเล่นซ้ำ · ต่อสาย `clip_pickimg` ·
  ผ่าไฟล์ใหญ่ · คอขวดมือถือ
