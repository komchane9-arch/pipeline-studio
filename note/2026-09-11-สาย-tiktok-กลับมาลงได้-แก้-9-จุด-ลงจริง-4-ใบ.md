## 1. สรุปข้อมูลทั้งหมด

### รากเหง้าเดียวที่อธิบายความล้มเกือบทุกครั้ง

**หน้าร้านค้าของ TikTok วาดเป็นภาพ ไม่ส่งตัวหนังสือออกมา**

```
หน้า ecommerce.*   ผัง 4,416 ตัวอักษร · อ่านชื่อปุ่มได้ 0 คำ
ตัวอ่านภาพเดิม     โมเดล ch_PP-OCRv4 รู้จักแค่จีน/อังกฤษ
                   "ร้านค้า" อ่านออกมาเป็น "Suusefu"
```

ด่านตรวจทุกขั้นของผัง TikTok หาคำไทย จึงล้มหมด ทั้งที่ภาพหน้าจอเห็นของที่หาชัดเจน

### ตัวขวางอื่นที่วัดได้จริง

| เรื่อง | หลักฐาน |
|---|---|
| กล่องขอสิทธิ์ Android บังจอ | ผังเป็นของ `com.google.android.permissioncontroller` |
| **ระบบปิดกล่องนั้นเองไม่ได้** | ลองครบ 3 วิธี (แตะ · ย้อนกลับ · swipe) ไม่ขยับสักวิธี — Android กันไม่ให้โปรแกรมกดยินยอมแทนคน **ต้องมีคนกด** |
| TikTok แทรกแท็บ "ถาม" | ทุกแท็บเลื่อนขวา 1 ช่อง พิกัดเดิมไปตกที่ "ดีที่สุด" |
| ร่างค้างจากรอบก่อน | เปิดแอปใหม่แล้ว TikTok กู้ร่างขึ้นมาแทนหน้าแรก |
| `uiautomator dump` ล้มเงียบ | ตอบ `ERROR: could not get idle state.` แล้วโค้ดไปอ่านไฟล์เก่าที่ค้าง |

### ตัวเลขที่วัดได้

```
ตัวอ่านภาษาไทย EasyOCR   โหลดโมเดล 17 วิ · อ่านภาพ 1.4 วิ (ใช้ RTX 3070)
                          อ่าน "เพิ่มสินค้าหรือไม่" · "ยกเลิก" · "ไม่ต้องแสดงอีก" ได้ครบ
                          แต่ทำวรรณยุกต์ตก: "เพิ่ม" → "เพิม"
ผังหน้าฟีดปกติ            45,585 ตัวอักษร · อ่านชื่อปุ่มได้ 19 คำ
ผังตอนมีกล่องสิทธิ์บัง     7,867 ตัวอักษร · อ่านชื่อปุ่มได้ 0 คำ
```

## 2. สรุปผลงานทั้งหมดในแชทนี้

### ลงจริง 4 ใบ ยืนยันด้วยตาจากโปรไฟล์ `@artaiitgadget`

| ใบงาน | สินค้า | เวลา |
|---|---|---|
| 7004541327 | Ugreen สายชาร์จเร็ว PD100W | 12:37 |
| 22368983533 | UGREEN ฮับ USB-C 10-in-1 | 13:49 |
| 4059590733 | Ugreen ฮับ Type C 10 in 1 | 13:55 |
| 15466071713 | TCL แอร์ติดผนัง SaveIN | 14:03 |

**3 ใบหลังผ่าน 14/14 ขั้นรวดเดียว ไม่ต้องมีคนช่วยเลย** และยืนยันผลได้เอง

### แก้ 9 จุดใน `tiktok_publish_bot.py`

1. **`get_thai_ocr()`** — ใส่ตัวอ่านภาษาไทย (EasyOCR) ไม่แตะตัวอ่านเดิมที่สายโพสต์อื่นใช้
2. **`thai_loose()` + `seen()`** — เทียบคำแบบยอมวรรณยุกต์ตก **เฉพาะผังที่มาจากการอ่านภาพ**
3. **`find_bounds` รอบสุดท้าย** — หาพิกัดปุ่มแบบยอมวรรณยุกต์ตกด้วย
4. **`blocking_system_dialog()`** — แยก "ไม่เจอของที่หา" ออกจาก "มีกล่องระบบบังจนอ่านไม่ได้"
5. **`dismiss_soft_prompts()`** — รู้จักกล่องขอสิทธิ์ Android · **ตอบ "ไม่อนุญาต" เสมอ ไม่กดให้สิทธิ์**
6. **`why_blocked()`** — ข้อความล้มบอกสาเหตุจริง ไม่ใช่แค่ "ไม่พบ X"
7. **`leave_leftover_draft()` + `settle_activity()`** — ถอยออกจากร่างค้าง เกาะ**ชื่อหน้าจอ**ไม่ใช่ตัวหนังสือ และรอจนหน้าจอนิ่งก่อนตัดสิน
8. **พิกัดแท็บร้านค้า** `(145,178,270,258)` → `(250,185,355,252)` · **`shop_results_visible()`** เลิกใช้คำว่า "ร้านค้า" เป็นด่านแรก หันไปเกาะชิป MALL/LIVE + ราคา
9. **`profile_tiles()` + `new_clip_on_profile()`** — ตัวตรวจผลโพสต์ตัวที่สอง อ่าน**ยอดเล่นซึ่งเป็นเลขล้วน**

### เปลี่ยนกติกาที่สำคัญที่สุด — ตรวจไม่ได้ให้ถือว่า "ลงแล้ว"

```
เดิม   ตรวจไม่ได้ → บันทึก "ล้มเหลว" → ระบบลงซ้ำ → ถอนไม่ได้
ใหม่   ตรวจไม่ได้ → บันทึก "ลงแล้ว" + ปิดอัตโนมัติ + เตือนให้ไปดูด้วยตา
```

**สองความเสี่ยงไม่เท่ากัน** — บันทึกว่าล้มทั้งที่ขึ้นแล้วทำให้ลงซ้ำซึ่งถอนไม่ได้
ส่วนบันทึกว่าลงทั้งที่ยังไม่ขึ้น แค่ใบนั้นหาย สั่งลงใหม่ได้

### แก้ `app.py` 1 จุด (ไฟล์ส่วนกลาง จองและคืนแล้ว)

## 3. สรุปงานค้างที่ต้องทำต่อทั้งหมด

### รอเจ้าของตัดสิน

- **จะเปิดสวิตช์รันต่อเนื่องไหม** — ตอนนี้ `tiktok_publish = False` ยังปิดอยู่
- **ใบที่เหลือ 27 ใบใช้ทางเก่า (มีแต่ลิงก์ ไม่ได้เพิ่มโชว์เคส)** ยังไม่เคยทดสอบวันนี้
- **อีก 269 ใบยังไม่มีสินค้าผูก** ต้องเปิดตัวหาสินค้า (`tiktok_link`) ซึ่งยังไม่ได้ทดสอบ
  และเป็นตัวเดียวกับที่ทิ้งรูปค้างจนทำให้ Facebook โพสต์ผิด 3 ใบเมื่อ 10 ก.ย.

### รอเราทำต่อ

- **บันทึกชื่อบัญชีผิด** — ลง TikTok แต่จดว่าบัญชี `Squishy cute club` (ชื่อเพจ Facebook)
  ทั้งที่ของจริงคือ `@artaiitgadget` · กระทบการนับโควตา 70 คลิป/วันซึ่งนับแยกรายบัญชี
- **ร่างค้าง 2 ใบ** ในแอป ควรเก็บทิ้ง
- **ไฟล์อ้างอิงตรวจโพสต์สำเร็จเป็นของ 3 ก.ย.** TikTok เปลี่ยนหน้าไปแล้ว ควรถ่ายใหม่
- **`uiautomator dump` ล้มเงียบแล้วคืนไฟล์เก่า** — ใส่ด่านกันในสคริปต์ทดสอบแล้ว
  แต่ยังไม่ได้ใส่ในตัวโปรแกรมจริง
- **`tiktok_publish_bot.py` ยังไม่เคยเข้า git** (`??` ใน git status) ควร commit

### เรื่องที่ผมทำพังเองแล้วกู้คืนแล้ว

สั่งติดตั้ง EasyOCR แบบไม่ล็อกรุ่น มันอัปเกรด `numpy` เป็น 2.x แล้วล้มกลางคัน
ทำให้ `cv2` และ `rapidocr` (ตัวที่ระบบโพสต์ทั้งหมดใช้) พัง และ `torch` ถูกเปลี่ยน
จากรุ่น GPU เป็น CPU — **กู้คืนครบทุกตัวแล้ว** และตรวจแล้วว่าใช้งานได้จริง

บทเรียน: ลงของใหม่ในเครื่องที่มีระบบรันอยู่ **ต้องใช้ `--no-deps` แล้วเติมตัวที่ขาด
ทีละตัว** พร้อมจดรุ่นเดิมไว้เทียบก่อน-หลังทุกครั้ง
