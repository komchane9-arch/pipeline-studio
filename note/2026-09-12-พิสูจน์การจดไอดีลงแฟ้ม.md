# พิสูจน์การจดไอดีลงแฟ้ม — ปิดช่วงสุดท้ายที่พิสูจน์ได้เอง

**12 กันยายน 2569 (รอบสาม)** · ต่อจาก
[แก้ตัวอ่านไอดีหลังดูบัญชีจริง](2026-09-12-แก้ตัวอ่านไอดี-tiktok-หลังดูบัญชีจริง.md)

---

## 1. สรุปข้อมูลทั้งหมด

เหลือช่วงเดียวที่ยังไม่ได้พิสูจน์ — **อ่านไอดีออกแล้วจดลงแฟ้มได้จริงไหม**
อ่านออกแต่จดไม่ลง = ช่องนั้นยังขึ้นว่า "ยังไม่ได้ล็อกอิน" อยู่ดี เท่ากับ
ฟีเจอร์ไม่ทำงาน และช่วงนี้**ไม่ต้องรอบัญชีจริง** จึงทำได้เลย

---

## 2. สรุปผลงานทั้งหมดในแชทนี้

### `python tiktok_chromes.py พิสูจน์` เพิ่มเป็น 5 ขั้น (commit `52f684a`)

```
ก) หน้าจริงยังไม่ล็อกอิน + วางชื่อคนอื่นเป็นกับดัก 6 ชื่อ  -> ปฏิเสธ           ผ่าน
ข) ก้อนหน้า Studio แบบเข้ารหัส HTML                    -> @komchan.shop   ผ่าน
ค) ก้อนหน้าแรก                                        -> @komchan.shop   ผ่าน
ง) จดลงแฟ้มแล้วอ่านกลับมาได้                            พร้อมใช้ True      ผ่าน
จ) รอบถัดไปอ่านไม่ได้ ไอดีเดิมยังอยู่ + ติดธงว่าเก่า                          ผ่าน
```

ขั้น (ง) กับ (จ) เดินผ่าน**ตัวจดของจริง** โดยใช้แฟ้มชั่วคราว ไม่แตะข้อมูลจริง

ขั้น (จ) สำคัญพอๆ กับ (ง) — ถ้าลบไอดีทิ้งทุกครั้งที่อ่านไม่ได้ วันที่เน็ตสะดุด
ครั้งเดียว ช่องที่ล็อกอินไว้แล้วจะขึ้นว่า "ยังไม่ได้ล็อกอิน" แล้วเจ้าของจะไป
ล็อกอินซ้ำโดยไม่จำเป็น

### พิสูจน์ว่าขั้นใหม่จับของพังได้จริง

```
ทำให้ตัวจดไม่เก็บไอดี  ->  รหัสจบ 1 · ฟ้องว่าขั้น "จดไอดีลงแฟ้ม" ไม่ผ่าน ไอดีเป็น None
โค้ดปกติ              ->  รหัสจบ 0
```

### เทสแบบไม่ต้องต่อเน็ต 13 ข้อ

เพิ่มอีก 4 ข้อเรื่องการจด รวมข้อที่แยก "ยังไม่เคยตรวจ" ออกจาก "ตรวจแล้วไม่ผ่าน"

### เก็บกวาด

ลบข้อมูลขยะจากการทดสอบก่อนหน้าออกจากแฟ้มจริง (`flow_browser_profile`
ซึ่งไม่ใช่ช่องของระบบ) · ไม่มีโฟลเดอร์ชั่วคราวค้าง

## 3. สรุปงานค้างที่ต้องทำต่อทั้งหมด

### รอเจ้าของ

- **ล็อกอิน TikTok ในช่องที่ต้องการ** — ทำแทนไม่ได้ (ห้ามกรอกรหัสผ่าน
  ห้ามสร้างบัญชีแทน) ช่อง 1 เปิดรออยู่แล้ว · ใช้ "Use QR code" เร็วที่สุด
- **คอนเฟิร์มสเปคหน้าเว็บ** `SPEC-ช่อง-chrome-tiktok.md`

### รอเราทำต่อ

- ต่อสายช่องพวกนี้เข้ากับการลงคลิปผ่านคอมจริง (ยังไม่ได้เริ่ม)
- `tiktok_product_link.py` ยังไม่ได้ใช้ `screen_read`
- ที่ว่าง 15 GB · `data/evidence` โตขึ้นเรื่อยๆ
