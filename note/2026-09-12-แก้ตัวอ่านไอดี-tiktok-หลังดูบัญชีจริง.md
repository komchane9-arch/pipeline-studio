**12 กันยายน 2569 (รอบสอง)** · แก้ของที่บันทึกไว้ก่อนหน้านี้ในวันเดียวกัน
ไฟล์เดิม [พิสูจน์ตัวอ่านไอดี TikTok บนหน้าเว็บจริง](2026-09-12-พิสูจน์ตัวอ่านไอดี-tiktok-บนหน้าเว็บจริง.md)
**สรุปเร็วเกินไป** — อ่านไฟล์นี้ประกอบเสมอ

## 1. สรุปข้อมูลทั้งหมด

### สิ่งที่บันทึกไว้ก่อนหน้านี้ผิดตรงไหน

รอบก่อนพิสูจน์ด้วยการเปิดหน้าแรก TikTok **ตอนยังไม่ล็อกอิน** แล้วเติมก้อน
บัญชีเข้าไปเอง ซึ่งผ่านหมด แต่นั่นคือ**คนละหน้า**กับหน้าที่ใช้งานจริง
ตรงกับกติกา 2.2 เป๊ะ — *ตรวจในสภาพเดียวกับที่ใช้งานจริง ไม่ใช่สภาพที่สะดวกวัด*

### ตรวจทั้งเครื่องแล้วพบว่ามีบัญชีล็อกอินอยู่จริง

```
Chrome ส่วนตัวของเจ้าของ  Profile 6, 11, 14   มี sessionid / sid_tt ครบ
Edge ส่วนตัว              ไม่มี
โปรไฟล์งานในโปรเจกต์      ไม่มี
```

จึงเปิดแท็บใหม่ในเบราว์เซอร์ของเจ้าของ **อ่านอย่างเดียว** ไม่ปิดอะไร
ไม่แตะการตั้งค่า ไม่ยุ่งกับรหัสผ่าน เสร็จแล้วปิดแท็บที่เปิดเอง

### สิ่งที่เจอ — ของเดิมใช้กับหน้าจริงไม่ได้เลย

```
หน้า Studio ตอนล็อกอินแล้ว   ไม่มีก้อน __UNIVERSAL_DATA_FOR_REHYDRATION__
                             เลยสักตัว  (hasBlob: false)
```

ตัวอ่านเดิมอ่านแต่ก้อนนั้น จึงจะตอบว่า "ล็อกอินแล้วแต่อ่านไอดีไม่ได้" ทุกครั้ง
— จัดประเภทถูก แต่จำไอดีไม่ได้อยู่ดี

### ที่อยู่จริง วัดจากบัญชีที่ล็อกอินอยู่

| หน้า | ก้อน | ที่อยู่ | ค่าที่ได้ |
|---|---|---|---|
| Studio | `__Creator_Center_Context__` (เข้ารหัส HTML) | `commonAppContext.user.uniqueId` | `taiwhatsale` |
| หน้าแรก | `__UNIVERSAL_DATA_FOR_REHYDRATION__` | `__DEFAULT_SCOPE__["webapp.app-context"].user.uniqueId` | `taiwhatsale` |

ทั้งหน้า Studio มีคำว่า `uniqueId` อยู่ **ที่เดียว** ไม่มีชื่อคนอื่นปนเลย
ต่างจากหน้าแรกตอนยังไม่ล็อกอินที่มีชื่อคนอื่น 3 ชื่อ

ชื่อช่อง `uniqueId` ที่เดาไว้**ถูก** แต่ก้อนที่ไปอ่าน**ผิด**

## 2. สรุปผลงานทั้งหมดในแชทนี้

### `tiktok_chromes.py` (commit `a666985`)

- อ่านทั้งสองก้อน ถอดรหัส HTML ให้ด้วย
- **สองแหล่งให้ไอดีไม่ตรงกัน = ไม่เดา ไม่เลือกข้าง** เพราะจดผิดช่องแล้ว
  คลิปขึ้นผิดบัญชี ถอนไม่ได้
- ตอนอ่านไม่ได้ หลักฐานจะจดว่าแต่ละก้อนมีหรือไม่มี และชื่อบัญชีโผล่ตรงไหน
  (ทดสอบแล้ว ได้ `__Creator_Center_Context__: ไม่มีก้อนนี้บนหน้า`)

### เทส 9 ข้อ ใช้ค่าที่วัดจากของจริงทั้งหมด

รวมข้อที่ตรวจว่าสคริปต์ยังถามครบทั้งสองก้อน — ใครลบก้อนไหนออก เทสฟ้องทันที

### `python tiktok_chromes.py พิสูจน์` วัด 3 ขั้นบนหน้าจริง

```
ก) วางชื่อคนอื่นเป็นกับดัก 6 ชื่อ        -> ปฏิเสธ            ผ่าน
ข) ก้อนหน้า Studio แบบเข้ารหัส HTML   -> @komchan.shop    ผ่าน
ค) ก้อนหน้าแรก                        -> @komchan.shop    ผ่าน
```

## 3. สรุปงานค้างที่ต้องทำต่อทั้งหมด

### รอเจ้าของ

- **ล็อกอิน TikTok ในช่องที่ต้องการ** — ทำแทนไม่ได้ (ห้ามกรอกรหัสผ่าน
  ห้ามสร้างบัญชีแทน) ช่อง 1 เปิดรออยู่แล้ว
- **คอนเฟิร์มสเปคหน้าเว็บ** `SPEC-ช่อง-chrome-tiktok.md`

### รอเราทำต่อ

- ต่อสายช่องพวกนี้เข้ากับการลงคลิปผ่านคอมจริง (ยังไม่ได้เริ่ม)
- `tiktok_product_link.py` ยังไม่ได้ใช้ `screen_read`
- ที่ว่าง 15 GB · `data/evidence` โตขึ้นเรื่อยๆ
