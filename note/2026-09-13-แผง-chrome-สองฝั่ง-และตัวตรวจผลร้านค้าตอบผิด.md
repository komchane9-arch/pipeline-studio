# แผง Chrome ทั้งสองฝั่ง · ของที่หายไประหว่างทาง · ตัวตรวจผลร้านค้าตอบผิด

**13 กันยายน 2569** · ต่อจากงานรวมบัญชี Flow 7 ใบ
เจ้าของสั่ง *"ตรง tiktok ก็ทำเหมือนกัน พอกดดู chrome ค่อยให้มี chrome เด้งขึ้นมา"*
แล้วต่อด้วย *"ไม่ต้องรอผมล็อคอิน ทำงานของคุณให้เสร็จ"*

## 1. สรุปข้อมูลทั้งหมด

### แผง TikTok ยังไม่เคยถูกสร้างบนหน้าเว็บเลย

สเปคส่งไว้ตั้งแต่ 11 ก.ย. แต่ค้างอยู่เพราะรอเจ้าของคอนเฟิร์ม
`grep tiktok/chromes web/*.js` = 0 ที่ จึงใส่พฤติกรรมซ่อน/เด้งเข้าไปในสเปค
ตั้งแต่ต้น สายกลางจะได้ทำรอบเดียวจบ

### ตัวตรวจผลร้านค้าตอบว่า "ยังไม่โหลด" ทั้งที่หน้าจอถูกต้องทุกประการ

ใบงาน 29708428217 ล้ม 11 ก.ย. 16:48:12 — เปิดภาพตอนล้มมาดูแล้วพบว่า
แท็บร้านค้าถูกเลือกอยู่ · ชิป MALL/LIVE ขึ้นครบ · สินค้า 4 ใบพร้อมราคา

```
บนจอจริง        MALL      ฿179.75   ฿283.48
ตัวอ่านภาพได้    mall      8179.75   8283.48
ตัวตรวจถามหา    "MALL"    (ราคาจับได้ครบ 6 ตัวอยู่แล้ว)
```

ตัวอ่านภาพคืนตัวพิมพ์เล็กเสมอ ตัวตรวจเทียบตรงตัวจึงไม่เจอสักชิป

### แผง TikTok — เทสในหน้าเว็บจริงของเจ้าของแล้ว

```
เปิดหน้ามา 9 วินาที   ยิงขอข้อมูล 0 ครั้ง (ดักนับที่ตัวยิงจริง)
กดปุ่ม 👁 ดู Chrome   ยิง 2 ครั้ง · ขึ้นครบ 7 ช่อง · ป้ายเป็น "ซ่อน Chrome"
กดซ้ำ                หุบกลับ เหลือ 0 ช่อง · จำค่าไว้ · อีก 8 วินาทียิง 0 ครั้ง
```

### ของที่หายไประหว่างทาง — ขอคืนแล้ว

ปุ่ม `👁 ดู Chrome` ใต้กอง ดึง Link / Storyboard เดิมเปิด Chrome ของขั้นนั้นตรงๆ
ตอนนี้ทั้งสามปุ่มกลายเป็นสวิตช์กาง/หุบแถบ Flow อันเดียวกัน ตรวจของจริงแล้ว

```
ดึง Link (Shopee)      flow_browser_profile3   อยู่ในแถบเครดิต = ไม่
Storyboard (ChatGPT)   flow_browser_profile    อยู่ในแถบเครดิต = ไม่
เจน Clip               komchand9               อยู่ในแถบเครดิต = ใช่
```

แถบเครดิตลิสต์เฉพาะบัญชี Flow 7 ใบ **สองบานนั้นเปิดจากหน้าเว็บไม่ได้อีกแล้ว**
และเป็นสองบานที่ต้องให้คนดูบ่อยที่สุด (Shopee โดนบล็อก · ChatGPT หลุดล็อกอิน)

### `note` ที่บอกสายกลางให้ใช้ — ไม่มีจริง เขาจับได้

เขายิงเส้นตรวจเองก่อนเขียน จึงไม่ได้ทำช่องว่างเปล่าที่ไม่มีวันขึ้น
ต้นเหตุ: `save()` จดเหตุผลลงไฟล์อยู่แล้ว แต่ `rows()` ประกอบ dict เองทีละคีย์
แล้วไม่มี `note` — เหตุผลจึงตายอยู่ในไฟล์ · แก้แล้ว ส่งเฉพาะแถวที่มีปัญหา
(แถวปกติ note คือคำว่า "ผ่าน" ส่งไปด้วยจะขึ้นเตือนใต้ทุกแถวที่ยังดีอยู่)
และเลิกตัดเหตุผลที่ 80 ตัวอักษร ประโยคจริงยาว 82 เดิมขาดกลางคำว่า "ตลอด"

### ตัวตรวจผลร้านค้า

```
Corrective  เทียบชิปแบบไม่สนตัวพิมพ์ใหญ่เล็ก · ใบที่เสียไปมีใบเดียว
Preventive  เพิ่มแถวเรียงลำดับ (ตรงกันมากที่สุด · สินค้าขายดี · มีคะแนนสูงสุด)
            เป็นหลักฐานสำรอง มีเฉพาะแท็บร้านค้าและตัวอ่านภาพอ่านออกครบ
```

**ทำไมไม่มีใครจับได้** — เทสเดิมเล่นซ้ำเฉพาะผังจากระบบ ซึ่งมี ฿ จริงและชิป
ตัวพิมพ์ใหญ่จริง ทางที่อ่านจากภาพไม่เคยมีเทสครอบเลย ทั้งที่เป็นทางที่ใช้จริง
บนหน้านี้ (หน้ามีนาฬิกานับถอยหลังเดินตลอด ผังจากระบบจึงอ่านไม่ได้)

เพิ่มเทสแล้ว และพิสูจน์ว่าถอดการแก้ออกเทสล้มจริง
ตรวจไม่ให้หละหลวมขึ้นด้วยการเล่นซ้ำผังเก่า **297 ไฟล์ ไม่มีไฟล์ไหนเปลี่ยนคำตอบเลย**

## 3. สรุปงานค้างที่ต้องทำต่อทั้งหมด

### รอเจ้าของ

- **ล็อกอิน Flow 3 บัญชี** — komchanc9 · komchanx9 · komchany9
- **ล็อกอิน TikTok** ช่องไหนก็ได้ใน 7 ช่อง
- **ใบงาน 29708428217 กด Resume ได้แล้ว** — ไม่ได้สั่งรันเอง เพราะเป็นการโพสต์ขึ้นจริง

### รอสายกลาง

- คืนปุ่มเปิด Chrome ของขั้น ดึง Link และ Storyboard

### รอเราทำต่อ

- **ใบงาน 5 ใบค้างที่ขั้นเพิ่มโชว์เคส** (29931737200 · 44163776779 · 27629895577
  · 25025138544 · 22088601141) ล้มวันที่ 7–10 ก.ย. ด้วยข้อความ "กดเพิ่มในโชว์เคสแล้ว
  แต่หน้าจอไม่ยืนยันผลสำเร็จ" — ตัวอ่านภาษาไทยเพิ่งใส่เข้าไป 11 ก.ย. 14:38
  **ตอนนั้นระบบอ่านคำยืนยันภาษาไทยไม่ออกเลย** จึงน่าจะเป็นการล้มทั้งที่สำเร็จแล้ว
  ยังไม่ได้ไปตรวจบนเครื่องว่าสินค้าเข้าโชว์เคสไปแล้วจริงไหม
- `tiktok_product_link.py` ยังไม่ได้ใช้ `screen_read`
- ที่ว่างในเครื่อง 15 GB · `data/evidence` โตขึ้นเรื่อยๆ

### ตรวจแล้วว่า **ไม่ใช่ปัญหา** (จะได้ไม่ไปไล่ซ้ำ)

- บั๊กตัวพิมพ์ใหญ่-เล็กที่จุดอื่น — `thai_loose()` ทำ casefold ให้อยู่แล้ว
  ส่วนที่เทียบตรงตัวที่เหลือเป็นกล่องของระบบ Android ซึ่งอ่านจากผังจริงได้
  ไม่ได้ใช้ทางอ่านภาพ **ไม่แก้เพิ่มโดยไม่มีหลักฐาน**
- การดึงข้อมูลของแผงหนักไหม — วัดแล้ว 32 มิลลิวินาที (TikTok) และ
  179 มิลลิวินาที (Flow) ไม่ต้องแต่งอะไรเพิ่ม
- ช่องเจนคลิปไปใช้บัญชีที่ห้ามไว้ไหม — ทั้งสองช่องใช้ komchand9 ไม่ได้แตะ komchane9
