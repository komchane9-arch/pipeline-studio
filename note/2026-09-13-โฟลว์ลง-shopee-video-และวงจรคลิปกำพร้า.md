## 2. วงจรที่ทำให้สายตายเงียบ — ล็อกกันเองสองทาง

### อาการ

สายลง Shopee หยุดยาวโดยไม่มีอะไรฟ้อง นอกจากเลข "0/22 ขั้น" ที่ไล่ต่อไม่ได้
เกิด **2 ครั้งในรอบ 12 ชั่วโมง** ต้องมีคนเข้าไปลบไฟล์มือทั้งสองครั้ง

```

วันนี้   10:27 → 11:18   ล้ม 6 รอบ   ปิดสายไป 51 นาที
```

### ไล่ทำไม

```
ทำไม 1   ด่านตรวจไม่ยอมให้ลง เพราะเจอคลิปสองใบในโฟลเดอร์ที่ควรมีใบเดียว
ทำไม 2   ใบเกินคือคลิปของงานก่อนหน้าที่ลงเสร็จไปแล้ว แต่ไฟล์ยังค้าง
ทำไม 3   ในเส้นทางลง Shopee **ไม่มีขั้นลบไฟล์ของใบอื่นก่อนส่งใบใหม่**
         (app.py:2124 เรียกตัวล้างเฉพาะ facebook_reels กับ tiktok)
ทำไม 4   คนเดียวที่เก็บคลิปกำพร้าคือ "ตัวล้างเครื่อง" ซึ่งเดินเป็นรอบ
ทำไม 5   ตัวล้างเครื่อง **ถูกสั่งให้พักเมื่อมีใบงานค้างรอ Resume**
```

**รากเหง้า** — ใบที่ค้างรอ Resume คือใบที่ค้าง**เพราะ**คลิปกำพร้า
และคลิปกำพร้าจะถูกเก็บก็ต่อเมื่อไม่มีใบค้าง สองอย่างนี้กันกันเอง

## 4. คำสั่งที่ใช้เฝ้าและตรวจ

```bash
tail -f data/logs/publish.log                  # เหตุผลจริงตอนล้มอยู่ไฟล์นี้
tail -f data/logs/clip.log                     # ตัวสั่งงานและผลรวม
python phone_queue.py board                    # ใครถือจออยู่
python publish_order.py <item_id>              # ใบนี้ลงอะไรไปแล้ว ลงอะไรต่อได้
adb -s W4FYYPYTLFYLIFHM shell "ls -l /sdcard/Movies/autopost"   # มีคลิปกำพร้าไหม
```

**ตรวจก่อนลบคลิปในเครื่องทุกครั้ง** — ต้องครบสามอย่าง
1. ใบเจ้าของไฟล์ลงปลายทางนั้นสำเร็จแล้ว (`publish_order.py`)
2. ต้นฉบับยังอยู่บนคอม `data/shopee_products/<id>/video/clip.mp4`
3. **ขนาดไฟล์ตรงกันเป๊ะ** กับที่อยู่ในเครื่อง

แล้วลบโดยถือ `phone_lock` เสมอ
