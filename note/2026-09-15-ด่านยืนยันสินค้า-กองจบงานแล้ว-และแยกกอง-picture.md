### 1.3 ผลการตรวจคลิปว่ามีมือ/คนไหม

```
ตรวจ 296 ใบ ใน 357 วินาที (1.2 วินาที/ใบ)
ไม่มีมือและไม่มีคนเลย  190 ใบ = 64%
มีมือหรือคนในฉาก       106 ใบ = 36%
```

**ทำไมไม่ใช้ qwen ตัดสิน** — วัดจริงบนเครื่องนี้

```
ตัดเฟรมด้วย ffmpeg      1.9 วินาที/คลิป   (ไม่ใช่คอขวด)
qwen2.5vl:7b ตัดสิน     53 วินาที/คลิป    -> 296 ใบ = 4 ชั่วโมงครึ่ง
สาเหตุ                  ollama รันบน CPU ล้วน (size_vram = 0.0 GB)
                        เครื่องนี้ไม่มีการ์ดจอ NVIDIA (torch.cuda เห็น 0 ใบ)
MediaPipe + YOLO        1.7 วินาที/คลิป   -> 8 นาที (เร็วกว่า 31 เท่า)
```

ตรวจความแม่นด้วยตาเทียบเฟรมจริง **4 ใบ ถูกทั้ง 4** รวมเคสยากคือจานรองแก้ว
ที่มีมือโผล่แค่ 1 ใน 8 เฟรม ตัวตรวจก็จับได้

### 2.5 ความผิดพลาดของตัวเองในรอบนี้

1. **ลง mediapipe/ultralytics ทับของเดิม** → pip อัปเกรด numpy เป็น 2.x แล้วล้ม
   กลางคัน ทำให้ numpy · cv2 · EasyOCR ใช้ไม่ได้ชั่วคราว (เซิร์ฟเวอร์ที่รันอยู่
   ไม่กระทบเพราะโหลดไว้แล้ว) — กู้ครบและย้ายไป venv แยก
2. **สรุปว่า "ไม่มีใครเรียก `clip_info`"** ทั้งที่ grep ตัดไฟล์ที่มันอยู่ออก
   → ส่งสเปคผิดให้สายกลาง
3. **เผลอลบโค้ด `clip_app.py` 4,571 บรรทัด** เพราะใช้ `str.index` ค้นข้อความที่ซ้ำ
   ได้หลายที่ — กู้จาก git ทันที ครบ 11,417 บรรทัด
4. **ใส่ธงด่านยืนยันไว้สองชุด** ทำให้สองที่อยู่ตอบไม่ตรงกัน 4 ใบ สายกลางจับได้
5. **ตัวกรองคลิปที่ผมรันครั้งแรกหยาบเกินไป** ฟ้อง 7 ใบแต่เสียจริง 2 ใบ
