## ปัญหาทางเทคนิคที่เจอระหว่างทาง (เผื่อมีประโยชน์วันหลัง)

**เจนล้มทั้ง 4 แบบในรอบแรก** — `Could not load libtorchcodec`

torchaudio ตั้งแต่รุ่น 2.9 ย้ายไปใช้ตัวอ่านเสียงชื่อ torchcodec ซึ่งต้องการไฟล์
ไลบรารีของ FFmpeg **แบบแยกเป็น .dll** แต่ ffmpeg ในเครื่องนี้เป็นแบบรวมไฟล์เดียว
(gyan.dev full build) ตัวอ่านจึงหาไม่เจอแล้วล้มทุกครั้ง

**แก้ได้ด้วยการเปลี่ยนไปใช้ soundfile อ่านแทน** โดยแพตช์ `torchaudio.load`
และ `torchaudio.save` **ก่อน import f5_tts** (ถ้าแพตช์ทีหลังจะไม่ทัน)

```python
import soundfile as sf, torch, torchaudio, numpy as np
def load(path, *a, **k):
    data, rate = sf.read(str(path), dtype="float32", always_2d=True)
    return torch.from_numpy(np.ascontiguousarray(data.T)), rate
torchaudio.load = load
```
