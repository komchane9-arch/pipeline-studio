# เซิร์ฟเวอร์ดับทั้งชุดตอนแอป Claude อัปเดตตัวเอง — 24 ก.ย. 2569

## บทสนทนา

- **ผู้ใช้ (09:0x):** "ทำไมเว็บถูกปิด http://127.0.0.1:8866/"
- **เรา:** ไล่หาสาเหตุ เปิดเซิร์ฟเวอร์กลับ แล้วแก้ตัวรีสตาร์ตไม่ให้เกิดซ้ำ

## ไล่หาสาเหตุ (Why-Why)

**อาการ** — 09:04 เปิด 8866 ไม่ได้ ไม่มีโปรแกรม Python รันอยู่เลย (หน้าเว็บ ·
สายคลิป 8877 · บอทแมส ดับหมด)

1. **ทำไมดับ** — log ทุกตัวหยุดพร้อมกันที่ 23:28–23:29 ของ 23 ก.ย. ทั้งที่เป็นคนละโปรแกรม
   และไม่มี error สักบรรทัด (publish.log 23:29:23 · clip.log 23:28:54 · input.log 23:28:52)
2. **ทำไมพร้อมกัน** — เครื่องไม่ได้รีสตาร์ต (เปิดต่อเนื่องตั้งแต่ 23 ก.ย. 12:50)
   แต่บันทึก Windows เขียนว่า `Claude VM Service stopped` 23:29:34 "during package servicing"
   และ `Claude.exe` ทุกตัวเริ่มใหม่ 23:29:36–37 → แอป Claude อัปเดตตัวเอง
3. **ทำไมแอป Claude อัปเดตแล้วเซิร์ฟเวอร์ดับตาม** — `restart_studio.py` เปิด app.py ด้วย
   `Popen(DETACHED_PROCESS)` ซึ่งแค่ไม่ผูกหน้าต่าง แต่ Windows ยังจดพ่อ-ลูกไว้ ตัวรีสตาร์ต
   ถูกเรียกจากแชท Claude เซิร์ฟเวอร์จึงเป็นหลานของ claude.exe
4. **พิสูจน์** — จำลองปิดทั้งสายพ่อลูก (`taskkill /T`):
   เปิดแบบ Popen เดิม **ตายตาม** · เปิดผ่าน WMI (`Win32_Process.Create`) **ยังอยู่**

**Root cause** — วิธีเปิดเซิร์ฟเวอร์ทำให้มันอยู่ในสายพ่อลูกของแอป Claude
**ทำไมไม่รู้ตัว** — ไม่มีตัวตรวจว่าเซิร์ฟเวอร์ "อยู่ใต้ใคร" · ดับแล้วไม่มีอะไรเตือน เงียบ ~9.5 ชม.

⚠️ **ยังไม่ได้พิสูจน์ 100%** ว่าแอป Claude ปิดโปรแกรมด้วยวิธีปิดทั้งสาย — ที่พิสูจน์ได้คือ
เวลาตรงกันเป๊ะ และวิธีใหม่รอดการปิดทั้งสายในการจำลอง ต้องรอดูตอนแอปอัปเดตครั้งหน้า

## Corrective

- 09:06 เปิด `start_studio.bat` ผ่าน WMI → 8866 ✅ · 8877 ✅ · บอทแมส ✅
  พ่อของ app.py เป็น cmd ที่เปิดจากตัวบริการ WMI ไม่ใช่แอป Claude
- **กู้ไม่ได้:** งานที่ควรเดินระหว่าง 23:29 → 09:06 (ตอบคอมเมนต์ · เก็บยอด · สายคลิป) ไม่ได้ทำ

## Preventive

- `restart_studio.py` เปิดเซิร์ฟเวอร์ผ่าน WMI แทน Popen · WMI เปิดไม่ได้ = ล้มดัง ไม่ถอยไปใช้ Popen
- ตรวจหลังเปิดทุกครั้ง `under_claude(pid)` — ถ้าเซิร์ฟเวอร์ใหม่ยังอยู่ใต้ claude.exe ให้ฟ้องทันที
  (ทดสอบแล้ว: เซิร์ฟเวอร์เมื่อเช้า → ไม่อยู่ใต้ · โปรแกรมที่เปิดจากแชท → `claude.exe`)
- 🔵 ยังไม่ได้ทำ: ตัวเฝ้าที่เตือนเมื่อเซิร์ฟเวอร์ดับ (ตอนนี้ดับแล้วไม่มีใครรู้จนเปิดหน้าเว็บ)
- 🔵 `start_studio.bat` ถ้าเรียกจากแชทยังอยู่ใต้ Claude — ดับเบิลคลิกเองจาก Explorer ปลอดภัย
