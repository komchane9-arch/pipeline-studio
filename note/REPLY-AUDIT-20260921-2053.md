## Why-Why และข้อจำกัด

1. สี่รายการยังขึ้นรอยืนยัน เพราะ send_reply ไม่ได้ผลยืนยันจาก verify_on_phone.
2. verified_reply ใน fb_reply_safe.py ต้องพบชื่อ+ข้อความต้นทางตรงเต็มหนึ่งแถว รูปโปรไฟล์ต้นทาง คำตอบที่เยื้องเข้าไป ชื่อบัญชีผู้ตอบตรง และข้อความตรง รวมถึง reply button ของคำตอบใน XML snapshot เดียว หากขาดข้อใดจะคืน False โดยไม่ระบุข้อที่ตก.
3. verify_on_phone อ่าน 7 รอบ เลื่อนขึ้นครั้งละ 350 หน่วยอ้างอิงได้ 4 ครั้ง ไม่สะสมหลักฐานความสัมพันธ์ข้ามจอและไม่คืนไปหาต้นทาง. จึงมี failure mode ที่คำตอบยาวทำให้ต้นทางหลุดจอ หรือคำตอบไม่มีปุ่มตอบกลับในจอ แม้ส่งสำเร็จจริง. ยังพิสูจน์ไม่ได้ว่าข้อใดเกิดกับแต่ละรายการ เพราะไม่มี snapshot ณ เวลาล้มเหลวที่ค้นพบ.
4. Ruby เข้าสาขาพบชื่อ+ข้อความแล้วแต่ reply=None ของ _find_queued_comment ใน fb_engage.py. ระบบเลื่อนเพิ่มหนึ่งครั้งและอ่านใหม่ หากยังไม่มีแถวตรงพร้อมปุ่มจะหยุดทันที. ข้อความ error นี้ไม่ได้หมายความว่าหาคอมเมนต์ไม่เจอแต่แรก และไม่มีการส่งจาก attempt นี้. สาเหตุที่ parser ไม่ได้ปุ่มจริงยังยืนยันไม่ได้.
5. visible_comments ใน facebook_group_post.py แบ่งแถวด้วยตำแหน่งรูปโปรไฟล์ และรับปุ่มเฉพาะ clickable label ที่ขึ้นต้นตาม REPLY_BUTTON_PREFIX ในช่วงแถวนั้น. ต้องตรวจภาพ+XML จริงเพื่อแยกปุ่มนอกจอ รูปแบบ label เปลี่ยน หรือแบ่งขอบแถวผิด.

## การตรวจโพสต์จริงที่ยังติดขัด

เครื่องมือ node_repl สำหรับ Computer Use เริ่มไม่ได้: failed to write kernel assets: The system cannot find the path specified. (os error 3). Reset แล้วลองใหม่ยังล้มเหลว; cua_repl ให้ข้อผิดพลาดเดียวกัน. ยังไม่ได้เปิดโพสต์จริงในการตรวจครั้งนี้ จึงยังยืนยันสาเหตุรากรายคนและสถานะ Facebook จริงไม่ได้.

## แนวแก้ที่ควรตรวจยืนยันก่อนทำ

- บันทึก XML/ภาพและเหตุผลข้อที่ verification ไม่ผ่านแยกรายคน.
- อ่านคำตอบหลายจอพร้อมรักษาหลักฐาน parent/thread; ไม่บังคับว่าต้องมีปุ่มตอบกลับบน child เพื่อพิสูจน์การส่ง.
- หาปุ่ม Ruby ด้วยการอ่านแถวใหม่และเลื่อนตามขอบเขตจริงหลายขั้นอย่างมีขีดจำกัด พร้อมตรวจชื่อ+ข้อความทุกครั้ง.
- เปิดลิงก์จริงทั้ง 4 โพสต์ กางคำตอบ ตรวจบัญชีผู้ตอบ ผู้รับ ข้อความและลิงก์ก่อนเปลี่ยนสถานะ. สี่รายการ submitted ต้องตรวจผลเท่านั้น ไม่ส่งใหม่.

ไม่มีการแก้โค้ดรันจริง เปลี่ยนสถานะคิว หรือส่งคอมเมนต์ในการตรวจครั้งนี้.
