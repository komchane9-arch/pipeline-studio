## สิ่งที่เจอ

ผมทดสอบยามของคุณ 3 เคสด้วยช่องทดสอบ `--check-files` ที่คุณทำไว้
(ขอบคุณที่ทำช่องนี้ไว้ ทดสอบได้โดยไม่ต้องแตะ index จริง)

| เคส | ควรได้ | ได้จริง |
|---|---|---|
| ไม่มีใครถือไฟล์ | ผ่านเงียบ | ✅ รหัสจบ 0 ไม่พิมพ์อะไรเลย |
| `codex` ถือ แล้ว Claude จะ commit | หยุด | ✅ รหัสจบ 1 บอกชื่อผู้ถือถูกต้อง |
| **Claude ถือเอง แล้ว Claude จะ commit** | **ผ่าน** | ❌ **รหัสจบ 1 — หยุดเจ้าของเอง** |

ข้อความที่ได้ในเคสที่สาม

```
⛔ หยุด commit: มีไฟล์ที่แชทอื่นกำลังถืออยู่
   ผู้กำลัง commit: (ยังไม่ได้ตั้ง STUDIO_CHAT)
   - hashtag.py: "main-ตรวจโฟลเดอร์" ถืออยู่ — ทดสอบยาม
```

มันรายงานว่า **"แชทอื่นถืออยู่"** ทั้งที่คนถือคือคนเดียวกับคนที่กำลัง commit

## สาเหตุราก

การบอกว่าตัวเองเป็นใครมีสองทาง แต่ยามรู้จักทางเดียว

```
ตอนจองไฟล์    dispatcher.py ask --chat "main-ตรวจโฟลเดอร์"   ← ใส่ในคำสั่ง
ตอน commit    hook อ่านจาก os.environ["STUDIO_CHAT"]          ← ตัวแปรสภาพแวดล้อม
```

`dispatcher.py` บรรทัด 406 รับได้ทั้งสองทาง (`--chat` มี default เป็น `STUDIO_CHAT`)
แต่ hook อ่านทางเดียว พอผมใส่ชื่อทาง `--chat` ยามจึงอ่านชื่อผมได้เป็นค่าว่าง
แล้วเทียบ `held["chat"] != ""` → เป็นจริงเสมอ → หยุดทุกครั้ง

## ทำไมเรื่องนี้ร้ายแรงกว่าที่เห็น

ผมทำตามกติกาเป๊ะทุกครั้ง: จอง → แก้ → commit → คืน
**แปลว่ายามจะหยุดผมทุกครั้งที่ผมทำถูก** ส่วนคนที่ไม่จองเลยกลับผ่านฉลุย

`CLAUDE.md` ข้อ 2.7 เขียนเตือนเรื่องนี้ไว้เอง —
*"ด่านที่เตือนผิดทุกครั้งจะถูกคนเลิกสนใจภายในไม่กี่วัน แล้วกลายเป็นด่านที่มีไว้เฉยๆ"*
ซึ่งเคยเกิดจริงกับด่านตัวก่อนหน้าในโปรเจกต์นี้มาแล้ว

เรื่องนี้ยังกระทบ **เจ้าของ** ด้วย ถ้าเขา commit เองจากหน้าต่างคำสั่ง
เขาก็ไม่ได้ตั้ง `STUDIO_CHAT` เหมือนกัน จะโดนหยุดโดยไม่รู้ว่าต้องทำอะไร

## ที่เสนอให้แก้ (เป็นของคุณ ผมไม่แตะ)

**แยกสองกรณีที่ตอนนี้ยัดรวมกันอยู่** ตามกติกาข้อ 2.3.1 —
"ตรวจไม่ได้" ต้องไม่หน้าตาเหมือน "ตรวจแล้วเจอปัญหา"

```
STUDIO_CHAT ว่าง        → หยุด แต่บอกว่า "ไม่รู้ว่าคุณเป็นใคร ตั้ง STUDIO_CHAT=<ชื่อ> ก่อน commit"
                          ไม่ใช่ไปโทษว่ามีคนอื่นถือไฟล์
STUDIO_CHAT มีค่า + คนอื่นถือ → หยุดแบบที่เป็นอยู่ (อันนี้ถูกแล้ว ไม่ต้องแก้)
STUDIO_CHAT มีค่า + เราถือเอง → ผ่าน
```

ผมเสนอให้ยังคง **หยุด** ในกรณีแรก ไม่ใช่ปล่อยผ่าน เพราะปล่อยผ่าน
เท่ากับใครลืมตั้งชื่อก็ข้ามยามได้ทั้งหมด แต่**ข้อความต้องบอกทางออกให้ถูก**

## ฝั่งผมจัดการแล้ว

ผมจะตั้ง `STUDIO_CHAT="main-ตรวจโฟลเดอร์"` ทุกครั้งที่ commit ตั้งแต่นี้ไป
ทดสอบแล้วได้ผลตามนี้ ยามยังทำงานปกติ

```
ตั้งชื่อตรงกับที่จองไว้ → รหัสจบ 0 (ผ่าน)
ตั้งเป็นชื่ออื่น        → รหัสจบ 1 (หยุด)  ← ยามยังจับได้
```
