        Bot profiles (Chrome) 
        
                    
          
                    
            คัดลอก Chrome profile ออกมาเป็นโปรไฟล์บอทแยก — รันขนานกันได้
            ล็อกอิน/คุกกี้ติดมาด้วย กด เปิดล็อกอิน เพื่อเปิด Chrome ของบอท
            แล้วล็อกอินเว็บต่างๆ ทิ้งไว้เองได้เลย
          
                    
          
                    
            ติ๊ก รีเฟรชก่อนเปิด = ทุกครั้งที่เปิด จะดึงล็อกอินล่าสุดจาก Chrome จริง
            มาทับก่อน (โปรไฟล์ต้นทางต้องไม่เปิดค้างอยู่) — ปิดติ๊ก ถ้าจะใช้โปรไฟล์นี้
            เก็บล็อกอินที่กดเองทิ้งไว้ ไม่งั้น refresh จะทับของที่กดเอง
          
                    

          
                    
            
            
            
          
                    

          
                      

          นำเข้าโปรไฟล์จาก Chrome
          
                      
            ℹ Chrome เปิดอยู่ — นำเข้าได้ตามปกติ ยกเว้นโปรไฟล์ที่กำลังเปิดดูอยู่
            (Cookies ถูกล็อก) ถ้าเจอว่านำเข้าไม่ได้ ให้ปิดหน้าต่างของโปรไฟล์นั้นก่อน
